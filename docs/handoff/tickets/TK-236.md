## 1. 문제 현상
동일 SHA(`9c63772f`)·동일 질의에서 `law_go_kr:판례검색(키워드)`가 2026-11-23 실행에서는 100건 정상, 2026-11-25 실행에서는 `ERROR`("자동 재조회 후에도 외부 출처 응답을 확보하지 못했습니다")로 갈렸다. 사건번호 지정 조회(`nb`)는 두 실행 모두 정상이었다. 즉 **키워드 검색 경로만 간헐적으로 실패**한다.

실패 시 사용자 영향: 사건번호가 없거나 형식이 깨진 인용의 보조 탐색 경로가 사라져, 실재하는 판례가 근거 없이 `UNVERIFIED`로 남는다.

## 2. 원인 가설과 확인해야 할 것 (구현 방법 미지정)
현 기록으로는 **원인을 특정하지 못했다.** 실패 메시지가 재시도 소진만 알리고 다음 정보를 남기지 않는다.
1. 공급자 HTTP 상태·본문 머리(한도 초과/점검/형식 변경 중 무엇인지)
2. 시도별 대기 시간과 총 소요
3. 응답이 왔으나 `_case_payload_shape_ok()`(`law_go_kr.py:711`)에서 형식 불일치로 버려졌는지 여부

## 3. 정량 수용 기준
- [ ] 외부 조회 실패 기록에 **공급자 HTTP 상태코드·응답 본문 머리(비밀값 마스킹, 200자 이내)·시도별 대기/소요·최종 분류**(`RATE_LIMITED` / `UPSTREAM_ERROR` / `SHAPE_MISMATCH` / `TIMEOUT`)가 남는다. 분류는 추측하지 않고 관측값으로만 정한다.
- [ ] 형식 불일치로 버린 응답은 `ERROR`가 아니라 **별도 분류**로 보고되어, 간헐 장애와 공급자 스키마 변경을 구분할 수 있다.
- [ ] 키워드 검색 실패가 사건번호 지정 조회 결과를 깎지 않는다(경로 독립성 회귀 시험).
- [ ] 양성 3건(한도 초과·업스트림 5xx·형식 불일치)·대조 3건(정상 200 응답·빈 결과 정상·단일 재시도 후 성공) 단위 시험. 외부 호출은 모의로 대체한다.
- [ ] 고정·은퇴 세트 회귀 0, 확인 오탐·A등급 오탐 0, CodeQL 새 경고 0.

## 4. 제약·불변식
- 비밀값(`OC`) 로그 노출 금지(`mask_oc()` 유지). 응답 본문 머리에도 질의 문자열의 `OC` 파라미터가 섞이지 않게 한다.
- 실패를 성공으로 둔갑시키지 않는다. 응답을 못 받은 조회는 `UNVERIFIED`로 남긴다(`Fail-Closed`).
- 재시도 횟수·대기를 늘려 공급자에 부담을 주는 방식으로 해결하지 않는다. 현 `max_attempts=2` 정책을 바꾸려면 근거를 적는다.
