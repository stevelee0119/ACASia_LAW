# TK-226 · P2 · Legal NLI Stage 2 의미 반전 인용 `SUPPORTED` 오분류 수정

- **우선순위:** `P2`
- **근거:** [0.25.0 온라인 평가 판정서](../../scorecards/online_0250_20261122.md) · [결함 요청 I-2](../online/0250_20261122/issues.md)
- **대상 모듈:** `packages/legal_engine/nli_verifier.py`, `packages/legal_engine/verifier.py`

## 1. 문제 현상
- `LV_LEGAL_NLI_MODE=assist`에서 공식 판례 전문(30,211자)을 확보한 반전 인용에 대해, 기존 1차 대조는 `CONTRADICTED`로 잡았으나 Stage 2 NLI가 `SUPPORTED`(중첩 0.9508)로 오분류하고 구조적 반전 사유를 0건으로 남겼다.

## 2. 정량 수용 기준 및 불변식
1. **방향/부정 구분:** 정확 인용은 `SUPPORTED`, 부정·예외·주체/방향이 반전된 인용은 `CONTRADICTED` 또는 근거 부족 시 `PENDING_REVIEW`로 분류하며, 공식 전문 미확보 시 `INSUFFICIENT`를 유지한다.
2. **진단 기록:** 선택 원문 대응 오프셋, 선택 구간 길이, 구조적 반전/극성 변화 이유를 기록한다.
3. **불변식:** 기존 1차 인용 대조의 정답 및 오탐(확인 오탐 0·A등급 오탐 0)이 악화되지 않으며, 고정·은퇴 세트 회귀 0을 유지한다.
4. **시험:** 서로 다른 판례/법조문 기반 정확·반전·상대방 전언/조건부 대조군 각 3건 이상의 단위 시험을 포함한다.

## 3. 부분 구현·잔여 이월 금지
- 특정 문구/사건번호 하드코딩 없이 일반 절·극성/부정 스코프 정렬로 해결한다.

## 4. 구현 설계 요약 (구현 에이전트 작성)
- **선택한 아키텍처/모듈(How)**:
  1. `packages/legal_engine/nli_verifier.py`: `_NEG_SURFACE_RE`에 한국어 법률 부정 활용형(`없는`/`아닌`/`아니한`/`못한`/`불가능`/`불인정` 등)을 보강하고 `_ANTONYM_PAIRS`(유효↔무효, 적법↔위법, 성립↔불성립, 허용↔불허/금지, 인정↔부인/배척/부정)를 추가했다. `_aligned_premise_span()`으로 다문장 원문 구간에서 가설과 가장 가까운 문장 구간을 정렬한 뒤 `_structural_inversion_reasons()`가 `QUOTE_DIFF_NEGATION`을 짝수/홀수 패리티로 누락하지 않고 `DEGREE`·`PROVISION_QUALIFIER`까지 포함해 극성/양태/반의어 반전을 탐지하도록 수정했다. 또한 `Stage2VerificationResult.to_dict()`에 `passage_offset`·`passage_length`를 기록했다.
  2. `packages/legal_engine/verifier.py`: 1차 대조(`level3 == "CONTRADICTED"` 또는 의미 변형 `diff_cats`)가 확인된 인용에 대해서는 Stage 2가 `SUPPORTED`를 유지하지 않도록 `PENDING_REVIEW` 보류 가드를 추가했다.
