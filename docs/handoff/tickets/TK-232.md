# TK-232 · P2 · `/api/diagnostics` `configured_mode`·`reranker_enabled` 표시 불일치 수정

- **우선순위:** `P2`
- **근거:** [0.26.0 온라인 평가 판정서](../../scorecards/online_0260_20261122.md) · [후속 관찰 2항](../online/0260_20261122/issues.md)
- **대상 모듈:** `apps/api/capabilities.py`, `packages/verification_engine/environment.py`, `packages/rag_engine/hybrid_retriever.py`

## 1. 관찰된 현상 및 사용자 영향
- 운영 환경에서 `LV_RAG_RETRIEVAL_MODE=lexical_only`로 설정해 재배포했음에도 `/api/diagnostics`에 `configured_mode=HYBRID`, `reranker_enabled=true`로 표시되었다(실제 실행 `effective_mode`는 `LEXICAL_ONLY`, 요청 0건).

## 2. 정량 수용 기준 및 불변식
1. **유효 설정 일치:** `LV_RAG_RETRIEVAL_MODE=lexical_only`/`off`/`lexical` 설정 시 `/api/diagnostics`와 `run_manifest`의 `configured_mode`가 `LEXICAL_ONLY`로, `reranker_enabled`가 실제 유효 상태와 일치하게 보고된다.
2. **실호출 분리:** `configured_mode`와 실요청 기반 `effective_mode`를 명확히 구분 유지한다.
3. **불변식:** 비밀값 미노출, 고정/은퇴 세트 회귀 `0`.
4. **시험:** `lexical_only`·`off`·`auto`(엔드포인트 유/무) 조합 양성 3건·대조 3건 단위 시험을 포함한다.

## 3. 부분 구현·잔여 이월 금지
- `capabilities.py`와 `environment.py` 중 한쪽만 고쳐 API 응답과 매니페스트가 어긋나지 않게 한 PR에 완결한다.
