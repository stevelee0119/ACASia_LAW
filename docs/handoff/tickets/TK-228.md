# TK-228 · P2 · Dense·Reranker 실제 어댑터 연결 및 로컬 모델 호출 경로 확보

- **우선순위:** `P2`
- **근거:** [0.25.0 온라인 평가 판정서](../../scorecards/online_0250_20261122.md) · [결함 요청 I-4](../online/0250_20261122/issues.md)
- **대상 모듈:** `packages/rag_engine/`, `packages/common/environment.py`, `config/providers.json`, `apps/api/capabilities.py`

## 1. 문제 현상
- `LV_RAG_EMBEDDING_ENDPOINT`·`LV_RAG_RERANKER_ENDPOINT` 등이 현재 `environment.py`의 진단 표시에서만 읽히고 실제 검색에는 어댑터가 전달되지 않는다. 또한 로컬 모델 공급자는 기본 비활성으로 실제 호출 경로가 연결되지 않았다.

## 2. 정량 수용 기준 및 불변식
1. **실제 어댑터 생성·호출:** 엔드포인트/로컬 공급자 설정 시 실제 어댑터가 생성·호출되며, 요청 수·성공/실패·폴백 이유에 기반해 `effective_mode`가 산출된다(단순 환경변수 존재만으로 `HYBRID` 표기 금지).
2. **안전한 폴백:** 원격/로컬 엔드포인트 미설정 또는 실패 시 안전하게 `LEXICAL_ONLY`/클라우드 폴백하며 폴백 사유를 기록한다.
3. **불변식:** Drive 기준 자료 신뢰 역할 및 입력 문서 지시문 탐지(`INJ-1`) 유지, 비밀값 미노출, 고정/은퇴 세트 회귀 0.
4. **시험:** 어댑터 실제 호출·실패 폴백·`effective_mode` 산출 양성 3건 및 대조 3건 이상 단위 시험을 포함한다.

## 3. 부분 구현·잔여 이월 금지
- 진단 JSON 필드만 추가하고 실제 검색/라우팅 파이프라인 연결을 생략하는 구현을 금지한다.
