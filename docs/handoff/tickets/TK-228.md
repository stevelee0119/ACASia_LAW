# TK-228 · P2 · 임베딩·재순위 서버의 실제 RAG 연결 (`I-4`)

- **우선순위:** `P2`
- **선행 조건:** **`TK-225`(`I-1` RAG 검색 `interrupted` 중단 해소) 완료 후 확대 적용**
- **근거:** [0.25.0 온라인 평가 판정서](../../scorecards/online_0250_20261122.md) · [결함 요청 I-4](../online/0250_20261122/issues.md)
- **대상 모듈:** `packages/rag_engine/`, `packages/common/environment.py`, `apps/api/capabilities.py`

## 1. 관찰된 현상 및 사용자 영향
- `LV_RAG_EMBEDDING_ENDPOINT`·`LV_RAG_RERANKER_ENDPOINT` 등이 현재 `environment.py` 진단 표시에서만 읽히고 실제 문서·주장 단위 검색에는 어댑터가 전달되지 않는다. 운영 실제 검색 모드는 `LEXICAL_ONLY`로 고정된다.
- 임베딩·재순위 서버가 준비돼 있어도 검색 품질·속도 효과를 측정하거나 활용할 수 없다.

## 2. 정량 수용 기준
1. **실제 어댑터 연결 및 저장·재사용:** 문서·주장 단위 검색에서 임베딩·재순위 어댑터를 실제 생성·호출하고, 청크 리비전별 임베딩을 저장·재사용한다.
2. **실제 요청 기반 `effective_mode`:** 진단의 `effective_mode`는 환경변수 존재 여부가 아니라 실제 요청 건수·성공/실패·폴백 사유로 산출한다.
3. **안전한 폴백:** 임베딩·재순위 서버 미설정 또는 호출 실패/타임아웃 시 어휘 검색(`LEXICAL_ONLY`)으로 안전하게 폴백하고 폴백 사유를 기록한다.
4. **ON/OFF 비교 및 반복 시험:** 동일 Drive 스냅샷에서 검색 순위·지지/무관 대조·지연시간을 ON/OFF로 비교하며, 검색 중단 재현 시험 및 `case9` 표준 23항목·RAG 5항목 반복 시험을 통과한다.

## 3. 불변식 및 재검증 방법
- **불변식:** 사건번호·조문 정확 일치 우선순위, 법적 적용성 필터, 무관 자료(`RAGC-N1`/`N2`) 배제, Drive 기준 자료 역할 분리 및 입력 문서 지시문 탐지(`INJ-1`) 유지, 비밀값 미노출, 고정/은퇴 세트 회귀 `0`.
- **오프라인·온라인 재검증:** 어댑터 실제 호출·청크 리비전 재사용·실패 폴백·`effective_mode` 산출 양성 3건·대조 3건 단위 시험(기존 `dev`/`holdout` 점수 상승과 분리 계측).
