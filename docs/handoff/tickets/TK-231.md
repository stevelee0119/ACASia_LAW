# TK-231 · P1 · 한국어 RapidOCR 이미지 전처리 및 Drive 저품질(`OCR_LOW_QUALITY`) 16쪽 선택 재색인 완결

- **우선순위:** `P1` (트랙 1 — 핵심 기능 실전화)
- **근거:** [0.26.0 온라인 평가 판정서](../../scorecards/online_0260_20261122.md) · [후속 관찰 1항](../online/0260_20261122/issues.md)
- **대상 모듈:** `packages/document_engine/ocr.py`, `packages/rag_engine/library.py`, `apps/api/`

## 1. 관찰된 현상 및 사용자 영향
- 0.26.0(`19efff6a`)에서 저품질 스캔(`clean_scanned.pdf` 대조 `low_quality_scanned.pdf`)에 `RapidOCR` 폴백이 채택되어 추출 글자가 `9자 → 25자`(주장 `0 → 2건`)로 늘었으나, 최종 페이지 품질이 `0.632`로 여전히 `OCR_LOW_QUALITY`에 머물렀다.
- 또한 운영 Drive 참고자료 `41/41`이 기존 캐시에서 그대로 재사용되어 기존 `OCR_LOW_QUALITY` 미완독 `16쪽`에 대한 RapidOCR 폴백 시도·채택이 `0쪽`이었다.

## 2. 정량 수용 기준 및 불변식
1. **저품질 이미지 전처리 후 RapidOCR 실행 (`ocr.py`):**
   - 1차 Tesseract 신뢰도가 임계값 미만인 저품질 이미지에 대해, RapidOCR 호출 전 **그레이스케일·적응형 대비/이진화·샤프닝(또는 해상도 업스케일)** 전처리를 적용해 `low_quality_scanned.pdf`에서 추출 글자 수·신뢰도를 개선하고 최종 페이지 상태가 `OCR_EXTRACTED`(신뢰도 기준 충족)로 복구되도록 한다.
   - 정상 스캔(`clean_scanned.pdf`, 신뢰도 `0.89`)은 불필요한 전처리·폴백 재처리가 `0건`이어야 한다.
2. **Drive `OCR_LOW_QUALITY` 쪽 자동/명시적 선택 재색인 (`library.py`, `apps/api/`):**
   - 전체 41개 문서를 처음부터 다시 내려받지 않고, 캐시된 문서 중 `OCR_LOW_QUALITY`(또는 OCR 추출기 버전이 구버전인 저품질 쪽)가 포함된 문서/쪽만 자동 감지하거나 명시적 옵션(`reprocess_low_quality=True`)으로 재OCR·재색인하는 경로를 완결한다.
   - 재처리 전후 `low_quality_pages_before`, `low_quality_pages_after`, `reprocessed_pages`, `recovered_pages`, `searchable_pages_delta`를 `coverage_ledger` 및 `run_manifest`에 기록한다.
3. **불변식:**
   - 실제로 글자 복구 기준(최소 글자 수·신뢰도)을 넘지 못한 빈 쪽/심각 손상 쪽을 거짓 `OCR_EXTRACTED`로 둔갑시키지 않는다.
   - 네트워크 차단 `Docker OCR readiness` 통과, 고정/은퇴 세트 회귀 `0`, 확인/A등급 오탐 `0`.
4. **시험:** 정상 스캔 비재처리 대조 3건·저품질 스캔 전처리+RapidOCR 복구 및 캐시 선택 재색인 양성 3건 이상 단위 시험을 포함한다.

## 3. 부분 구현·잔여 이월 금지
- 전처리와 Drive 캐시 저품질 재색인 두 축을 한 PR에 모두 완결한다.

## 4. 구현 설계 요약 (구현 에이전트 작성)
- `packages/document_engine/ocr.py`의 `RapidOCRAdapter`에 `_preprocess_low_quality_image()`(그레이스케일·해상도 업스케일·CLAHE 대비 향상·언샤프 마스킹 샤프닝)를 추가하고, `CompositeOCRAdapter.recognize_image()`가 1차 Tesseract 저품질 페이지에만 `preprocess=True`로 폴백을 호출하도록 연결하였다(정상 스캔은 전처리·폴백 `0건`, 빈 쪽은 거짓 복구 없음).
- `packages/rag_engine/library.py`의 `ReferenceLibrary.sync()`/`_sync_files()`에 `reprocess_low_quality` 옵션 및 `_needs_low_quality_ocr_reprocess()` 자동 감지를 추가해, 캐시된 전체 문서를 재다운로드하지 않고 `ocr_low_quality_pages`가 포함된 파일만 선택 재OCR·재색인하도록 구현하였다.
- 재처리 전후 `low_quality_pages_before`, `low_quality_pages_after`, `reprocessed_pages`, `recovered_pages`, `searchable_pages_delta`를 파일 메타와 `coverage_ledger["global_library"]`에 기록하도록 보강하였다.
- `tests/unit/test_tk231_ocr_preprocess_and_reindex.py`에 양성 3건·대조 3건 단위 시험을 추가하였다.
