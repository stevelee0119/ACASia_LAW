# TK-227 · P2 · 운영 Docker OCR 폴백 엔진 의존성 및 유효 설정 연결

- **우선순위:** `P2`
- **근거:** [0.25.0 온라인 평가 판정서](../../scorecards/online_0250_20261122.md) · [결함 요청 I-3](../online/0250_20261122/issues.md)
- **대상 모듈:** `docker/`, `requirements*.txt`, `packages/document_engine/ocr.py`, `apps/api/capabilities.py`

## 1. 문제 현상
- 저품질 스캔(신뢰도 0.611)에서 `FALLBACK_NOT_CONFIGURED`로 폴백 시도·채택이 0건이며, `/api/diagnostics`에서도 엔진 `none`·사용 불가를 보고한다. 배포 의존성 목록에 폴백 엔진(`rapidocr` 등)이 포함되지 않아 환경변수만으로 사용할 수 없다.

## 2. 정량 수용 기준 및 불변식
1. **배포 이미지 가용성:** 실제 배포 이미지(Docker OCR readiness 포함)에서 선택한 폴백 OCR 엔진이 사용 가능으로 진단된다.
2. **선택적 폴백·복구:** 저품질 쪽(신뢰도 임계값 미만)에서만 폴백이 시도되어 읽을 수 있는 본문/쪽 수가 증가하고, 정상 쪽(0.89 등)은 불필요하게 재처리되지 않는다.
3. **불변식:** 네트워크 차단 Docker OCR readiness 통과, 기존 오프라인 고정/은퇴 세트 회귀 0을 유지한다.
4. **시험:** 정상 스캔 대조 3건·저품질 스캔 폴백 양성 3건 이상 시험을 포함한다.

## 3. 부분 구현·잔여 이월 금지
- `capabilities.py` 진단 표시만 바꾸고 실제 Docker 이미지·OCR 어댑터를 연결하지 않는 부분 구현을 금지한다.
