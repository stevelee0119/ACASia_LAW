# TK-184 — 비율 계산 증거와 모델 사실 지적의 연결 누락

발견: 2026-11-15 · 우선순위 P2 · 유형 existing · 목표0.22.0 · 상태 원인 재현/수정 설계 단계.

실제 HWP 결과는 비율 오류를 결정론으로 잡았으나 같은 행 계산을 설명한 모델 지적을 UNCONFIRMED로 남긴다. 원본 보고서의 `_anchor_cover` 재실행에서도 연결0·미해결문장1을 재현했다.

원인: `packages/claim_engine/calculation.py`의 CALC.PERCENT_MISMATCH 증거는 합계와 사람이 읽는 행 설명 위주이고 행의 피연산자/비율/행 식별자를 구조화하지 않는다. `packages/verification_engine/ai_document_detector.py:value_anchors/verdict_anchors/_anchor_cover`에는 날짜·금액·조문만 있으며 비율 증거/행 연결이 없다. 해당 모델 문장에 있는 행 금액1개가 결정론 증거 앵커에 없어 안전하게 미확인으로 남는다.

반면 HWPX의 포괄적 모델 의견은 숫자/행 근거가 없다. 이 의견까지 '중복'으로 보고 자동 확인하거나 삭제하면 안 된다. 현재 사람 확인으로 남기는 동작을 유지해야 한다.

해결 설계: 비율 오류에 table_ref·행 위치/이름·행 금액·합계·기재/계산 비율·파생 열합계와 근거를 구조화하고, 모델 지적의 각 수치/관계가 같은 문서/표/행에서 실제 재계산으로 확인될 때만 기존 finding에 연결한다. 다른 행의 같은 금액/비율, 틀린 피연산자, 가정/상대방 주장, 추가 미확인 문장은 별도로 남긴다. 값 일부를 무시하거나 같은 종류라는 이유만으로 확인하지 않는다.

수용: 양성3/대조3 이상, 실제 보고서 재현, 날짜/금액/조문 연결 기존 회귀와 입력/PII 보호. 새 공개 예시는 사건 문장을 복제하지 않는다. 현재는 수정 사본이 미검증이므로 제품 적용 지시가 아닌 설계/조사 요청이다. 평가 측 사본 검증 후 구체 패치를 확정한다.
