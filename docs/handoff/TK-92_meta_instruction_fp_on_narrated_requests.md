# TK-92 정상 서면이 절차 중단·생략을 서술하는 문장을 '문서 속 지시문'(META_INSTRUCTION) 의심으로 잡는다 (P2, 오탐, 기존, 평가 측 발견)
- 유형: 탐지 버그(오탐). 발견: 평가 측, 2026-10-19 #146 판정 중 비공개 탐침(오프라인, 0.13.1 제품 코드 `f5bc6c0`에서 재현).
- 탐침 문장은 일반화 측정에 계속 쓰므로 공개하지 않는다. 아래는 구조 설명이다.

## 1. 증상
- 보이는 본문의 정상 서술이 `META_INSTRUCTION` 의심(SUSPICIOUS, 참고 아님)으로 잡힌다. 0.13.1 기준 정상 서술 8건 중 2건이었다.
  - 상대방(피고 등)이 검증·조사 절차를 중단하라고 **요청했다**는 서술
  - 행정청이 심사 절차를 **생략한** 처분이 위법하다는 주장
- 원인 후보: `packages/adversarial_engine/patterns.py`의 검증 중단 패턴(검증·심사 + 중단·생략)이 주어·서술 구조(상대방 요청 인용, 과거 행위 서술, 관형형 '-한 처분')를 구분하지 않는다.

## 2. 요구
1. 다음 구조는 지시문으로 보지 않는다.
   - 다른 사람의 요청·주장을 인용하는 서술: '-라는 (피고의) 요청·주장', '-라고 요구하였다'
   - 과거 행위 서술과 관형형: '-한 처분', '-하였다'
   - 법률 판단 문장: '-은 위법하다'
2. 숨김 채널(TK-89)에서 나온 같은 문장은 지금처럼 의심으로 남긴다. 보이는 본문 문맥 판정에만 적용한다.
3. AI 수신자를 부르거나 명령형으로 끝나는 진짜 지시문은 다시 놓치지 않는다.

## 3. 시험·수용
- 합성 양성 3건(보이는 본문의 실제 지시문)과 대조군 3건 이상(위 서술 구조, 문장은 새로 짓는다). 실제 진입점 시험 1개.
- 점검표 1~7항. 고정·은퇴 오탐 0·A 0 유지, 인젝션 문서의 채널 득점 불변.
