# TK-185 — AI 반복 평가 조건 비교 및 전체/일부 범위 판정 품질

발견: 2026-11-15 · 우선순위 P1(평가 조건 오표시)/P2(범위 품질) · 유형 new · 목표0.22.0.

`scripts/ai_repeat_summary.py`의 현재 observe는 커밋을12자로 자르고 summarize의 same_condition은 커밋만 비교한다. 입력/정책/모델/Drive가 달라도 조건 동일이라고 표시할 수 있다. 이번 평가는 이 값을 그대로 쓰지 않고 원본에서 full SHA·입력SHA·사건/실행/보안설정·버전·Drive스냅샷을 독립 확인했다.

도구 수정 방향(평가 측): 전체 SHA, 문서별 입력SHA 집합, 정책/프로필/기준일/모델·프롬프트·규칙판/참고자료스냅샷을 비교한다. 필수 증거 누락은 동일로 취급하지 않고 불명확으로 기록한다. 서로 다른 두 모델/세 모델 참여는 auto라우팅의 정상 차이일 수 있어 호출모델 수만으로 정책 차이로 오판하지 않는다. 변경 항목을 원문 없이 이름/해시로 표시하고 여러 입력 문서는 별도 집계/거절하여 첫 문서만 대표값으로 쓰지 않는다. 이 구조 변경의 사본/시험은 아직 미검증.

동일 조건4회(사용자2회+자동2회) 관찰: AI_PARTIAL_GENERATION3 / AI_FULL_GENERATION_LIKELY1, 최다판정 일치75%, 최종UNCERTAIN0. 상위 AI관여 기대 범주는4/4이나 정확도100%/전체생성 확인을 뜻하지 않는다. Anthropic은 부분판정으로 일관되고 다른 모델 범위 의견이 달라졌다. 객관적 생성흔적이나 작성 이력 정답이 없으므로 범위 판정의 참/거짓을 이 문서 하나로 확정하지 않는다.

품질 설계(구현/평가 분리): AI 관여 여부와 전체/일부 범위를 나눠 표시하고 모델 간 범위 이견·관찰 구간·표본 범위·근거 강도를 보존한다. 고정 라벨/점수 임계값을 이 사례에 맞춰 강제하지 않는다. 출처가 독립된 사람작성/일부AI/전체AI 대조군을 먼저 정해 반복 측정하고, 문체뿐인 판단을 객관적 생성 확인으로 표시하지 않는다. Gemini 기본모델 변경PR#304는 모델조건 변경이므로 수용 시 새로운 고정 조건 반복/공급자 호출 검증을 해야 한다.

수용: 같은SHA/다른입력·다른정책·다른모델·다른Drive·누락필드·복수문서 대조가 거짓 same_condition을 만들지 않음. 변경 전후 범위 판정은 같은 조건에서 별도 보고하고 한 결과만 골라 점수를 높이지 않음. 새 범위 품질의 합격 임계값은 독립된 정답/설계를 정한 뒤 평가한다.
