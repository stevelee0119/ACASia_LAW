# TK-213 재판행위 어간의 축약 활용 1꼴이 Time-Table 배제를 통과한다

- 발견일: 2026-11-19 (평가 세션, PR #342 2·3차 판정)
- 종류: 기존 기능 개선. **회귀가 아니다**(base `556dac84`에서도 실패한다)
- 상태: open

## 문제

`packages/claim_engine/extractor.py`의 `_PRECEDENT_AFTER_GENERIC_RE`는 재판행위 어간 뒤 음절이
`하`/`되`의 활용인지로 가른다. 그런데 `하게`가 `케`로 줄어든 축약 활용은 그 음절 집합에 없다.

평가 측 2차 확인 탐침 30칸 가운데 이 1칸이 base와 head에서 모두 실패한다(꼴: 법원 주격 +
날짜 + 재판행위 어간 + `케` 축약 + 인용 서술).

## 상태 — 사용자 결정 대기 (2026-11-19 정정)

[CLAUDE.md](../../CLAUDE.md)는 "미루려면 사유를 적고 **사용자 결정을 받는다**"고 정한다. 평가 측이
사유는 적었으나 **사용자 결정을 받지 않았다.** PR #345 사후 검토 지적으로 확인했다.

따라서 이 티켓의 보류는 아직 확정이 아니다. 아래 사유를 사용자에게 제시하고 결정을 받는다.
결정이 '이번 릴리스 포함'이면 TK-206의 4차 회차로 넣는다.

## 보류를 제안하는 사유

- base에서도 실패하므로 회귀가 아니다
- 법률 서면에서 드문 꼴이다
- PR #342는 세 회차를 돌았고, 평가 측 지시문 결함으로 회귀가 두 번 생겼다. 범위를 더 넓히면
  네 번째 회차가 된다. 2026-11-13 사용자 지시('처음 의도한 개선·보완은 그 릴리스에 포함')의
  취지는 **같은 요구의 미처리 부분**을 미루지 않는 것이고, 이 꼴은 base에서도 같던 잔여다

## 고칠 방향 (아직 지시하지 않았다)

음절 집합에 축약 활용을 더하는 것은 또 열거다. TK-206 1~3차에서 열거 방식이 네 번 빈틈을 냈다.
어간 뒤를 '하다/되다의 활용'으로 판정하는 자리를 음절 집합이 아닌 다른 구조로 바꿀지,
이 1꼴을 잔여로 둘지는 사용자 결정 뒤에 측정 근거와 함께 정한다.

## 미검증

축약 활용의 다른 꼴(`케` 외)이 더 있는지 전수로 보지 않았다.
