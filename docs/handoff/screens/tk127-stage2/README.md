# TK-127 2단계 화면 증빙

모두 새 합성 사건·가상 법령·합성 참고문헌으로 만들었다. 실제 사건이나 평가 세트 문장을 사용하지 않았다. 화면 수용은 사용자 확인 전이며 이 문서는 수용 판정이 아니다.

| 원문 요구 | 진입점 / 자료 |
|---|---|
| 공식데이터베이스 API에 추가로 Google Drive 자료 활용 | 01: 실제 검토 화면의 인용 행 3열에 출처·관계·328자 발췌 표시 |
| 구조적 연결은 허용, 식별자 부재 시 승격만 금지 | 02: 구조 연결 행의 부합 관계 배지와 참고자료 지지 미확정 상태 |
| 비구조 연결의 식별자 부재는 별도 행 | 02: 독립 참고문헌 대조 의견 행 |
| PDF·Word 인용 행의 근거 자료 열에 대조 의견 표시 | 03·04: 실제 생성한 초안 보고서의 표 3열, 상단/행별 비공식 안내 |
| Excel 안내 행·참고문헌 열·비공식 표시 | 05: 실제 생성한 참고문헌대조 시트 |
| JSON의 기계 판독 가능한 비공식성 메타데이터 | 06: 실제 JSON의 source=google_drive, official=false, binding=false, notice |

01·02는 합성 API 응답을 실제 app.js에 전달해 Edge에서 촬영했다. 보고서는 같은 합성 결과를 실제 `POST /api/projects/p1/reports`로 보내 생성했다. 03은 생성된 PDF 직접 렌더링, 04·05는 생성된 DOCX·XLSX 원본을 변경하지 않고 LibreOffice 25.8.7로 렌더링한 자료다. Microsoft Word·Excel 직접 표시 검증은 미실시다. 06은 실제 생성된 JSON 전체의 들여쓰기·줄바꿈만 정리한 브라우저 텍스트 표시다.

328자 긴 문장의 줄바꿈을 확인했다. PDF·DOCX의 길어진 행은 다음 페이지로 이어질 수 있다. 기존 보고서 서식의 범위를 넓혀 수정하지 않았다. 외부 AI 사용자 답변 영역과 Drive 참고문헌 영역은 합치지 않았다.
