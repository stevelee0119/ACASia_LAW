# TK-138 관련 판례 및 권위 가중 화면 증빙

합성 사건(임금 및 퇴직금 청구) 및 합성 참고자료 데이터로 렌더링했다. 실제 사건 및 평가 세트 문장을 사용하지 않았다. 화면 수용은 사용자 확인 전이며 이 문서는 수용 판정이 아니다.

| 파일명 | 해상도 | 진입점 / 표시 내용 |
|---|---|---|
| `01_related_precedents.png` | 1280 × 390 px | 참고자료/관련근거 탐색 패널 내 대법원 권위 판례 3건(전원합의체 포함) 및 긴 사건명 렌더링 화면 |

- 브라우저: Microsoft Edge (1280 × 390 뷰포트)
- U5 화면 문구 개선: 개별 판례마다 중복되던 검색 범위 괄호 겹침을 제거하고 머리글에 검색 범위(`대법원 본문검색 379건 중 100건 중 권위 순 정렬 상위 3건 · 검토 자료`)를 단일 표기하여 가독성 확보.
- 긴 사건명(예: `임금 및 퇴직금 청구의 소 (정기상여금의 통상임금 산입 여부 및 노사합의 무효에 따른 추가 법정수당 청구와 신의성실의 원칙 적용에 관한 전원합의체 판결)`)의 정상 표시 및 줄바꿈 확인.
