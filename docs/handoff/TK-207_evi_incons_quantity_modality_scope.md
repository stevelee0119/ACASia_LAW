- 종류: 기존 기능 개선. 회귀가 아니다(남은 8칸은 base `d79d6b21`에서도 실패한다).

## 문제

`packages/claim_engine/internal_inconsistency.py`의 수량 슬롯 가드가 **절 전체**를 훑어
미래·의도 서법을 판정한다. 그래서 어휘를 넓히면 낱말 안의 글자에 걸려 확정 수량을 떨어뜨리고,
좁히면 흔한 예정 서술이 빠져 오탐이 남는다. PR #336에서 두 방향을 모두 시도해 각각 실패했다.

| 회차 | 가드 | 결과 |
|---|---|---|
| 1차 `51546edd` | 없음 | 동사×미래 교차 100칸 중 100칸 오탐 |
| 2차 `a739fbf1` | `(?:예정\|계획\|하고자\|(?:할\|될)\s*것\|하겠\|되겠)` 절 전체 | 오탐 0이나 `사업계획서·납품예정표·예정일` 등 **낱말 안의 글자**에 걸려 확정 수량 9칸 미탐 |
| 3차 `7cd95476` | 서술어 결합 어휘 목록, 절 전체 | 과차단 해소. 그러나 `예정에 있다·계획 중이다·방침을 세웠다·복안이다` 등 8칸 오탐·미탐 잔존 |

## 남은 8칸 (base `d79d6b21`과 동일)

| 꼴 | 성격 |
|---|---|
| `납품 예정에 있다` · `납품 계획 중이다` · `납품하기로 예정되어 있다` | 오탐 |
| `납품 방침을 세웠다` · `납품을 계획하고 있다` | 오탐 |
| `납품 복안이다` · `납품 의향이다` | 오탐 |
| `공사할 터에 … 반입하였다` (보통명사 '터') | 미탐 |

## 고칠 방향 (평가 측 사본에서 검증)

낱말 목록을 더 늘리는 방식으로는 닫히지 않는다. **적용 범위**를 바꾼다.

1. 같은 파일의 날짜 경로는 이미 `pred_tail = clause[h_end:]`(`:1722-1723`)로 **서술어 꼬리에만**
   미래·부정을 검사한다. 이 선례를 수량 경로에 적용한다.
2. 수량 루프에는 이미 `following_q = clause[q_end:q_end+30]`(수량 바로 뒤 꼬리)이 계산되어 있다.
   가드를 절 전체에서 이 **꼬리 범위**로 옮기고 어휘는 넓게 둔다.
3. 꼬리 어휘는 **서술어에 붙은 꼴만** 받는다. `계획을 수립하였다`(목적어)·`터에`(처소)처럼 다른 격으로
   쓰인 낱말을 받으면 확정 수량이 다시 떨어진다 — 평가 측 사본에서 재현했다
   (`원고는 기계 40대를 납품하였으며 공급 계획을 수립하였다`가 과차단됨. `-으며`로 절이 나뉘지 않는다).
