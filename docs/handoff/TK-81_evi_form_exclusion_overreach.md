# TK-81 EVI-FORM 제외 규칙이 진짜 결함까지 지운다 (P2, 재현율, #125 `ab3b168` 후속 버그 수정)
- 유형: 탐지 버그(제외 규칙 과잉). 새 탐지 추가가 아니다. 범위 마감 뒤에도 받는 '버그 수정'에 해당한다.
- 발견: 평가 측, 2026-10-18 #125 `ab3b168` 비공개 탐침. 고정·은퇴·train 점수에는 드러나지 않는다(모두 `d52a445`와 같다).
- 근거는 평가 측 비공개 탐침 집계뿐이다. 탐침 문장은 공개하지 않는다.

## 1. 증상
- `d52a445`에서 잡던 진짜 결함 2종을 `ab3b168`이 놓친다(비공개 양성 탐침 3/4 → 1/4).
  1. **'X밖에 + 제출 부정'**: 'X(사본 등)만 낼 수 있었다'는 뜻으로 원본 미제출을 자인하는 문장이다. 새 '추가 제출 없음' 제외 규칙이 `밖에`를 '그 밖에'와 같이 보고 결함에서 뺀다.
  2. **자기 측의 '-다고 하나/-지만'**: 작성자 자신이 원본 분실 등을 인정하면서 인용 어미와 역접으로 잇는 문장이다. `_EVI_FORM_NON_DEFECT_CONTEXT_RE`에 추가된 `(다고|라고)…(지만|나)` 대안은 **주어 조건이 없어** 자기 측 진술까지 뺀다. 상대방 주어 조건이 있는 같은 규칙이 상대방 배제 블록에 이미 있으므로 이 대안은 중복이다.
- 남은 오탐 1종: 상대방 주장을 관형형('-었다는 피고의 지적·주장')으로 받아 '사실과 다르다'로 반박하는 문장을 자기 호증 기재 누락으로 잡는다.

## 2. 요구
1. `_EVI_FORM_NON_DEFECT_CONTEXT_RE`의 주어 없는 `(다고|라고)…(지만|나|였으나…)` 대안을 지운다. 상대방 배제 블록의 주어 조건 규칙만 남긴다.
2. '추가 제출 없음' 제외에서 단독 `밖에`를 빼고 `그\s*밖에|이\s*밖에`처럼 '그 밖의 다른 것'을 뜻하는 꼴만 남긴다. 'X밖에 + 부정'은 결함 쪽으로 둔다.
3. 상대방 주장 관형형('-다는/-라는 + (상대방) + 주장·지적·말') 뒤에 부정 평가('사실과 다르·이유 없·근거 없')가 오면 결함에서 뺀다. 상대방 주어 조건을 유지한다.
4. 다른 탐지 변경은 하지 않는다.

## 3. 시험
- 1·2 각각 양성 시험 2건 이상(이 문서와 다른 문장), 3 대조 시험 2건 이상.
- 기존 `tests/test_evidence_form_defects.py`는 지우거나 약화하지 않는다.
- 점검표 1·3항과 고정·은퇴·train 불변(평가 측 재실행으로 확인).
