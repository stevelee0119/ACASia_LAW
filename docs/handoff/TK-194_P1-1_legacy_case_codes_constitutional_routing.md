## 발견 내용

구 사건부호·재심 사건부호와 공식적으로 허용되는 사건번호 구분자 변형이 충분히 정규화되지 않아 인용을 놓칠 수 있었다. 법원명 없이 표기된 헌법재판소 결정 인용이 일반 사건으로 분류되거나 상세 조회 경로가 잘못 선택될 수 있었고, 불일치하거나 식별 불가능한 상세 레코드를 검색 결과에 결합하면 사건 간 교차오염 위험이 있었다.

## 구현 반영

PR #326은 사건부호 목록과 구분자 정규화를 확장하고 헌재 인용의 별도 조회 경로를 추가했다. 상세 레코드는 사건번호, 공식 연결 키 및 의미 도메인이 확인될 때만 병합하며, 불일치·불명확 값은 fail-closed로 차단한다.

## 운영 수용 기준

- 지원 대상 구 사건부호와 공식 구분자 변형이 올바르게 추출·정규화되어 조회된다.
- 헌재 인용은 헌재 결정 조회 경로로 라우팅된다.
- 상세 레코드의 사건번호·공식 키 불일치 또는 불투명 식별자는 병합되지 않는다.
- 거절된 상세 응답 때문에 검색 단계의 유효한 공식 자료가 손실되거나 다른 사건 자료로 대체되지 않는다.
- 온라인 결과에 사건번호·사건 당사자 등 원문 식별값을 기록하지 않는다.
