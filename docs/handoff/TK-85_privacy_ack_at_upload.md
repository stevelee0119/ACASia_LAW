# TK-85 개인정보 가림 안내를 상시 표시에서 업로드 시점 확인으로 바꾼다 (P3, 사용성, 사용자 개선안 1)
- 근거: 사용자 개선안(2026-10-19) 1항. 기존 요구는 [업로드 안내 지시서](PROMPT_FOR_UPLOAD_PRIVACY_NOTICE.md) 1항('파일 추가 근처 상시 안내')이었고, 사용자가 이번에 바꿨다.

## 1. 현재
- 자료 패널에 안내문과 확인 체크가 늘 보인다(`apps/web/index.html` 자료 패널, `apps/web/static/app.js` 440~481행).
- 확인은 업로드에만 쓰인다. 서버는 업로드 요청에서 `privacy_ack`이 없으면 422로 거절한다(`apps/api/routers/projects.py` 339~344행).

## 2. 요구
1. 파일 선택·끌어 놓기를 할 때 확인 창을 띄운다. 창에는 현행 안내문(판 번호 포함)과 확인 체크를 둔다. 확인해야 업로드가 진행되고, 취소하면 업로드하지 않는다.
2. 같은 프로젝트·같은 세션에서 이미 확인했으면 다시 묻지 않는다(현행 기억 방식 유지). 자료 패널에는 '개인정보 안내 다시 보기' 링크 한 줄만 남긴다.
3. 바꾸지 않는 것: 서버 422 검사, 감사 기록(사용자·프로젝트·문서·시각·안내문 판), 안내문 판 관리, 보고서 머리 표시, 접근성(라벨 연결·키보드·`aria-live`).

## 3. 시험
- 서버 시험(`tests/test_upload_privacy_notice_api.py`)은 바꾸지 않는다.
- 화면 시험(`tests/test_upload_privacy_notice_browser.py`·`tests/test_frontend_upload.py` 등)은 새 흐름에 맞게 고친다. 고친 시험마다 '전에 확인하던 요구 → 새 시험의 확인 위치' 대응표를 PR에 낸다. 확인하던 요구가 하나라도 빠지면 불수용이다.
