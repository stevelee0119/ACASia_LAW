대상은 `https://verify-acas-law.onrender.com`의 main `684f3469028dc38e539345501191cc7c9832b13a`다. 2026-11-21 한국 시각에 `/api/health`에서 버전 `0.24.0`, DB `ok`를 확인했다. API prompt는 `v0.2`로 TK75 OFF였고, case9 보고서의 worker 설정도 OFF였다. 채점 규칙은 2판, 네트워크는 사용 가능 상태였다. 항목별 결과와 입력·보고서 SHA-256은 [결과 JSON](result.json)에 있다. 원본 보고서와 계정·자료 식별자는 비공개 보관했다.

## 개선이 필요한 기능과 추가 구현·운영 계측

- **RAG 지지 의견.** Drive가 `READY_WITH_UNREADABLE`에 이른 뒤에도 `RAGC-S3`는 3회 모두 실패했다. 목표 자료의 후보 청크 1개가 전달됐으므로 관계 판단·근거 연결을 재검토해야 한다. 청크 선택 통과만으로 지지 의견 완료로 처리할 수 없다.
- **OCR 저품질 16쪽.** 미독을 확정해 상태와 화면에 표시한 점은 확인했다. 실제 법률 자료 활용을 위해 원본 교체 또는 품질 개선 후 재색인 경로와 그 전후의 검색 가능 쪽 수 측정이 필요하다.
- **실제 Hybrid 검색.** 이번 `LEXICAL_ONLY` 기록만으로 Dense·Reranker의 정확도와 폴백 품질을 판단할 수 없다. 어댑터·모드·정답 청크가 고정된 온라인 양성·무관 대조가 추가로 필요하다.
- **Legal NLI와 OCR 폴백.** 현 운영 결과에서 Stage2 판단 및 저품질 스캔의 폴백 채택을 관찰하지 못했다. 공식 원문과 구간 오프셋을 가진 인용 반전 입력, 저품질·정상 스캔 짝 입력, 활성 설정 및 실제 경로 로그를 갖춘 시험이 필요하다.
- **근거 그래프의 정확성.** 사슬 단절 후보 3건은 생성됐으나 정답 판정 근거가 없다. 실제 누락·정상 연결의 독립 대조와 중복·오탐 점수를 마련해야 한다.
- **공식 Source 조회.** 특정 정확 조회 1건 불일치와 학술 Source 2건 실패가 이어진다. 공급자 원응답과 후보 필터 뒤의 일치 수를 분리해 원인을 확인해야 한다.

TK-216 오류 주입 시 `H-ENGINE` 반영, 로컬 모델·카세트 재생, Dense·Reranker, Legal NLI assist, 적응형 OCR 폴백, 실제 사건에 대한 근거 그래프 정확성은 이번 운영 조건에서 판정할 수 없었다. 각 항목은 기능의 구현 여부와 운영 활성 여부, 측정 여부를 다음 회차에서 분리해야 한다.
