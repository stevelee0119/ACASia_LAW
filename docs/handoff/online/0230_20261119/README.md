## 관찰 요약

서면9 개발 자료의 표준 23항목은 세 실행 모두 **23/23**이었다. 그러나 TK75가 `ON`이고 모델·Drive 스냅샷이 2026-10-10과 같다고 확인되지 않아 당시 **21/23과 증감을 비교하지 않는다.** 세 실행 모두 Drive 동기화 건강 `H-REF`와 지지 RAG 대조 `RAGC-S3`는 미충족이다. 외형상 AI 작성 판정은 3회 동일했지만 참고자료 라이브러리 해시가 달라 동일 조건 반복 성적은 계산되지 않았다.

새 기능은 35,674자 **합성** 서면 분석 완료(TK-199), 외부 AI 답변의 새로고침·다른 프로필 복원·삭제 유지(TK-203·204), 검토 표의 세 내용 열 분리(TK-205), 수량·날짜 모순 탐지와 정상 대조(TK-76)를 확인했다. TK-206은 합성 법리 서술의 날짜가 Time Table에 나타나 미충족이다. 실제 사용자 원본 35,674자 서면은 특정할 수 없어 그 원본 자체의 효과는 측정 불가다.

읽기 전용 공식 Source 실연동 점검은 동일 SHA에서 수행됐으며 strict 워크플로는 실패했다. 정확 사건 조회 1건 미조회, 현재 운영 기본 모델이 아닌 구형 Gemini 2개 모델 HTTP 404, Semantic Scholar rate limit을 원인별로 [문제 목록](issues.md)에 적었다. 기본 운영 모델의 서면9 호출은 실패하지 않았다. 결과를 실행 브랜치에 커밋하는 `live-integration.yml`은 평가 측 작업 범위라 이 세션에서 실행하지 않았다. 봉인 온라인 시험(U1)과 봉인 출제(U4)는 운영 세션의 자료·권한 범위 밖이므로 **측정 불가**이며, 어떤 성적도 추정하지 않았다.
