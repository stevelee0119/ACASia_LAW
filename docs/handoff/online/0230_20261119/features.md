# 신규 기능 온라인 관찰

대상 배포 SHA는 [health.md](health.md)의 전체 SHA다. 판정은 이 세션의 운영 실측에 한정하며 원본 사건 서면의 효과로 일반화하지 않는다. 합성 자료의 파일과 SHA-256은 [재사용 자료](../materials/README.md) `v1/manifest.json`에 있다.

| 기능 | 관찰 상태 | 실측 근거와 범위 |
|---|---|---|
| TK-199 대용량 입력 | 충족(합성 규모 경로) | 본문 정확히 35,674자인 합성 DOCX가 105.17초 만에 `PARTIAL_COMPLETED`까지 도달했다. 문서는 격리되지 않았고 `INPUT_PRIVACY_BLOCKED`도 없었다. 모델 호출 36건 모두 성공했다. `PARTIAL`은 Drive 동기화 문제에 따른 상태다. 원래 사용자의 35,674자 서면은 특정할 수 없어 그 원본에 대한 효과는 측정 불가. |
| TK-203·204 외부 AI 답변 영속 | 충족(측정 경로) | 합성 서면 분석에서 답변 저장·교체 후 새로고침, 독립 브라우저 프로필에서 같은 분석 열기, 서버 답변 전체 삭제 후 새로고침을 실측했다. 삭제 뒤 서버 답변 0건, 화면 답변 0건. 아래 캡처는 합성 입력만 표시한다. 삭제 조작은 API를 사용했으므로 화면의 삭제 버튼 자체는 측정하지 않았다. |
| TK-205 검토 표 역할 분리 | 충족(합성 대조) | 화면에 `위치` 외 3개 내용 열(`문서 주장 및 인용 내용`, `법리 검토 결과 및 근거`, `확인이 필요한 내용`)이 별도 표시된다. 합성 계산 오류 행에서 주장 금액, 검토 계산, 확인할 증빙이 서로 다른 내용으로 채워졌다. |
| TK-206 사실관계 중심 Time Table | 미충족 | 합성 서면의 법리·선례 서술에만 등장하는 날짜가 Time Table에 1행으로 표시됐다. 별도 당사자 사실 날짜도 표시됐다. 법리 서술 배제 조건이 깨진다. |
| TK-76 EVI-INCONS | 충족(합성 양성·음성 대조) | 합성 수량 불일치 1건과 일시 모순 1건이 각각 `EVI.INCONS_INTERNAL_QUANTITY`, `EVI.INCONS_INTERNAL_DATE`로 나왔다. 각 경고는 입력 문장의 모순과 맞았다. 입고·출고 단계가 다른 정상 대조는 추가 EVI 경고를 내지 않았다. |

TK-203·204는 답변 A 저장 → 답변 B로 교체 → 새로고침 → 별도 로그인 세션의 다른 브라우저 프로필 → 서버 답변 전체 삭제 → 새로고침 순서로 시험했다. 저장·교체·조회·삭제 API는 모두 HTTP 200이었다. 답변 B는 새로고침과 별도 프로필에 유지됐고, 답변 A는 사라졌으며, 삭제 뒤 되살아나지 않았다.
