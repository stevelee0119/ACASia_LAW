# OCR 온라인 재평가 합성 입력

두 PDF는 같은 가상 문장 네 줄을 이미지로 그린 시험 자료다. 실제 사건·인물·개인정보는 없다. [매니페스트](manifest.json)에 SHA-256과 0.24.0 운영 `684f3469`에서 관찰한 상태를 적었다.

각 PDF를 별도 평가 프로젝트에 업로드하고 같은 배포 SHA·OCR 설정으로 한 번씩 검증한다. 결과 JSON에서 문서의 `page_coverage`와 OCR 엔진 실행 기록을 함께 확인한다. 깨끗한 입력은 본문 추출을 유지해야 한다. 저품질 입력은 1차 OCR 품질, 폴백 호출·채택 여부, 최종 추출량을 비교한다. 이전 배포에서 저품질 입력은 신뢰도 0.611의 `OCR_LOW_QUALITY`였고 대체 엔진 채택 근거는 없었다. 새 배포의 결과를 이 관찰과 대조하되 성공 상태를 미리 가정하지 않는다.

실행이 끝나면 원본 결과를 비공개로 보관하고 두 평가 프로젝트를 삭제한다. 공개 기록에는 입력 해시, 배포 SHA, OCR 상태·품질 수치, 폴백 엔진판·채택 사유, 프로젝트 정리 건수만 남긴다.
