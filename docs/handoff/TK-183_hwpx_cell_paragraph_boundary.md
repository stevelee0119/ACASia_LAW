# TK-183 — HWPX 표 셀의 문단 경계 보존

발견: 2026-11-15 · 우선순위 P2 · 유형 existing · 목표0.22.0 · 구현 Antigravity.

운영 보고서의 D-C2는 병합/정상 계산은 보존하지만 한 셀의 두 문단을 공백으로 합친다. 인증된 원본 다운로드 후 기존 보고서의 SHA와 일치함을 확인했다. 원본HWPX XML에는 해당 셀의 문단2개가 별도로 존재한다. 동일 코드 파서 재실행에서 공백 결합을 재현했으므로 저장 변환 탓이라는 이전 미확정은 해소됐다.

원인: `packages/document_engine/hwp_parser.py:_hwpx_tables`가 셀의 각 p를 `" ".join(...)` 한다. 문단 구분자로 보존하고 중첩 표의 본문이 외부 셀에 섞이지 않는 조건을 유지한다. 공백/빈 문단의 처리 계약도 명시한다.

평가 사본 패치: `patches/TK-183_hwpx_paragraph_boundary_on_83d862e7.diff`. 운영 원본의 두 문단 보존 확인, HWPX/HWP/비율 계산 관련57시험 통과. 원래 시험1개가 공백 병합을 기대하므로 그 기대를 줄바꿈 보존으로 바꾸고, 두문단/세문단/빈문단 대조3개를 추가했다. 중첩 표 분리·문자중복 방지·병합·계산 관련 단언은 그대로 유지한다. 실제 제품/보호시험 파일에는 아직 적용하지 않았다.

수용: 동일 원본 및 일반화 대조에서 두 문단과 병합을 보존, 계산 오류2건과 정상 표 오탐0 유지. 원래 입력 보안/가시성 경계 유지, 최종 후보 전체/은퇴 게이트 및 실제 HWPX 보고서 재채점. 현재 운영 확정점수46/47은 배포 후 재측정 전까지 올리지 않는다.
