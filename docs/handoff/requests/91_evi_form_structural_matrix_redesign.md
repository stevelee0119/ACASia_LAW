## 2. 세부 구조 및 알고리즘 설계

### 2.1 호증 표지 없는 첨부 자료 경로 제거
- 이전의 `_ATTACHMENT_REF_RE` 및 `_ATTACHMENT_DEFECT_STATEMENT_RE` 및 단락 단위 별첨 결함 검사 블록을 완전 삭제.
- 본안 서면에서 법률상 형식적 결함(EVI-FORM) 판단 대상은 원칙적으로 서면의 증거목록 및 본문 인용에 실린 자기 호증(`갑 제N호증`, `을 제N호증`)으로 한정.

### 2.2 정상 실무 절차 사유 4종 보호 (`_EVI_FORM_PROCEDURAL_JUSTIFICATION_RE`)
미제출 술어가 '이 증거를 근거로 쓰면서 그 내용·원본이 없음'을 말할 때만 결함이며, 다음 절차적 정당화 사유가 붙으면 결함에서 제외:
1. **추가 증거 없음 / 추가 제출 안 함**: `"이 증거 외에 추가로 제출할 증거 자료는 전혀 없습니다"`, `"더 이상의 증거는 제출하지 아니합니다"`
2. **종전 서면 기제출 / 중복 첨부 생략**: `"종전 서면에 이미 제출하였으므로 중복 제출을 피하기 위해 별도 첨부하지 않습니다"`
3. **공적 전산 / 공적 장부 확인 가능**: `"등기사항전부증명서는 대법원 전산망을 통해 확인 가능하므로 별도 첨부하지 않습니다"`
4. **문서송부촉탁 / 문서제출명령 / 사실조회 신청 사유**: `"금융거래내역은 법원에 금융거래정보제출명령을 신청할 예정이므로 원본을 직접 소지하고 있지 않습니다"`

단락 단위 및 문장 단위에서 해당 패턴 검출 시 결함 판정을 건너뜀.

### 2.3 술어군의 문법 형태 확장 (어휘 목록 탈피)
- **(a) 필수 기재 부재 (`_EVI_FORM_BLANK_RE`)**:
  - 대상 명사: `작성자|명의인|작성명의인|진술인|작성인|본인|서명자|서명|날인|기명날인|서명날인|도장|인영|자필서명|작성일자|작성일|날짜|일자`
  - 상태 부정 일반형: `(?:되어|찍혀|들어가|남아|붙어|이루어져)\s*있지\s*(?:않|못|아니)`
  - 결손 술어: `공란|빈칸|비어(?:\s*있)?|누락|미기재|미날인|미서명|미작성|빠져(?:\s*있)?|결여|흠결`
  - 주어 존재 부정: `(?:이|가|은|는|도)\s*(?:전혀\s*)?(?:없|아니)`
- **(b) 실물·원본 부재 자인 (`_EVI_FORM_UNSUBMITTED_RE`, `_EVI_FORM_EXHIBIT_UNSUBMITTED_RE`)**:
  - 행위 부정 일반형: `(?:회수|복구|발급|확보|수집|입수|취득|교부|출력|제출|첨부|보관|소지)(?:하지|받지|되지|하고\s*있지|되어\s*있지)\s*(?:않|못|아니)`
  - 행위 불능 일반형: `(?:할\s*수\s*없|하기\s*어렵|하기\s*곤란|에\s*실패)`
  - 고유 동사: `내지\s*(?:않|못|아니)|찾지\s*(?:않|못|아니)|가지고\s*있지\s*(?:않|못|아니)`
  - 상실 술어: `분실|유실|망실|소실`
  - 주어 존재 부정: `(?:이|가|은|는)\s*(?:전혀\s*)?(?:없|아니)`
  - 미제출 상태에서 사본/번역문/요지만 제출 구조 포섭.
- **(c) 내용 판독 불가 및 일부 장·면 누락 (`_EVI_FORM_UNIDENTIFIABLE_RE`)**:
  - 일부 누락: `(?:일부|앞\s*면|뒷\s*면|마지막\s*(?:쪽|면|장|페이지)|특정\s*(?:쪽|면|장|페이지)|하단|상단|중간)\s*(?:쪽|면|장|페이지|내용)?\s*(?:누락|빠져|잘려|결손)`
  - 훼손 상태 + 불능 술어 일반형: `(?:판독|식별|확인|읽|알)(?:하기|할|을|기)?(?:\s*(?:이|가|은|는|도|을|를))?\s*(?:수\s*없|불가|불가능|어렵|곤란|힘들|못)|보이지\s*(?:않|못|아니)|확인되지\s*(?:않|못|아니)`

### 2.4 피고 서면 서명 줄 판별 (`_detect_author_party`) 견고화
- 서명/제출인 블록이 여러 줄로 묶인 경우(`b_text.splitlines()`)를 역순 탐색하여 피고/원고 서명 줄을 정확히 식별.
- `author_party == "피고"`로 판별되면 `my_party_chars = {"을", "소을"}`을 기본 보장하여, 피고 서면 본문의 `"피고는 을 제1호증 진술서를 제출하나..."`가 상대방 탄핵으로 오인되지 않고 자기 호증 결함으로 정상 처리됨.
