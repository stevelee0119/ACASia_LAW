# TK45: reference availability와 법리 소비 계약 분리 (제품 전 보완)

PR96/d3의 prototype은 원문 law/article/논항·결론 연결을 출력할 뿐 finding/effect sense/fulfillment는 false다. 그러나 넓은 finite 모양 `[가-힣]+…므로` 때문에 계획·준비·가정·붙여 쓴 보고 premise에서도 reference node가 생성된다. 이는 제품 finding은 아니지만 memo120의 “계획/보고/UNKNOWN 증명 없음”과 attachment-level 보고를 혼동시켰다. **그 문구는 downstream legal admissibility에 적용한다**고 정정하며 원래39 기대값/제품0를 유지한다. reference availability를 법리 증명으로 승격하지 않는다.

## 두 단계와 source 계약

reference node의 scope 문자열은 목표 후보 범위를 표시할 뿐 first-BODY/작성자/prefix 증거가 아니다. node에 `speaker_scope_verified=false`, `first_body_verified=false`, `legal_admissibility_verified=false`를 명시한다. 실제 consumer는 원래 전체 reading source → heading-only prefix → 첫 BODY/자기 단일 닫힌 명제 → quote/report/조건/actor/unknown qualification 보호를 **다시 원문으로** 증명해야 한다. 다른 POSITIVE나 다른 문장의 scope를 빌리지 않는다.

직접 부정은 이미 제한한 자기 configured argument/목적격/독립 하지-않-았-종결 구성만 admissible이다. absent polarity·다른 목적어·필요성·중첩·계획·부분·화자는 여전히 새 증명0이다. 효과의 참조 node에는 premise finite의 모양만 있으므로 그것은 실제 행위도 법적 효과도 아니다. 효과 consumer의 첫 좁은 admissibility spike는 독립 과거 완료 predicate의 **정확 유한형**만 추가 확인한다. 공적 근거는 NIKL [완료하다(完了), sense1](https://krdict.korean.go.kr/m/kor/searchResult?mainSearchWord=%EC%99%84%EB%A3%8C%ED%95%98%EB%8B%A4) “완전히 끝마치다.”(2026-10-11 공적 source 기록 `58fbae3`); 관측 `완료하였으므로/완료했으므로`는 원문 형태이며 분석용 자모를 원문 span으로 만들지 않는다. 이는 작성자의 predicate 형식 admission일 뿐 실제 이행·전체완료·사실·법적 충분성은 false다. 이 공적 lemma/sense/application을 분리하며 법률명사로 sense를 선택하지 않는다. 계획/준비/가정/보고 및 다른 미등록 finite의 의미는 추정하지 않고 새 법리 proof0다. 별도의 자기 effect argument/case/실제 받다 sense와 explicit normative adjunct를 증명하기 전에는 효과 finding0이다.

## 공개 반대·consumer·한계

공개 계획/준비/가정/공백 없는 reported premise4에서는 reference availability=true일 수 있지만 실제 normalized document를 받는 **test-only consumer**가 원래 source scope와 위 admissibility를 검증하여 legal proof=None이어야 한다. 정상 직접 부정 및 관측 과거 완료+명시 normative adjunct 양방향을 함께 비교한다. preamble·다른 section·인용/보고 도입은 첫 BODY 문구 자체가 같아도 consumer proof0이고, BODY-local label로 우회하지 않는다. 기존39는 source 연결 capability 그대로이며 consumer 보호는 별도 기대값이다.

제품 모듈/selector/finding/기존 UNKNOWN/기대값 변경0, 넓은 e21 의미층/관찰 재분류/소비자 면제 이식0. 이 prototype만으로 actual legal finding 증가 또는 원래 게이트 통과를 주장하지 않는다. 승인 시 별도의 source consumer 적용과 실제 TXT/PDF/DOCX/성능/동일 SHA CI·독립 감사 이후 정상8/8 및 부정·확장 strict increase로 판정한다. source 없거나 미증명 finite인 입력에서 계속 abstain하므로 원래 대상 개선 여부는 미측정이다.
