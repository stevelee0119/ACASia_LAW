# B-1 TK-91 EVI-OVR 3차 보완 설계 메모 보정본 (128_tk91_evi_ovr_design_revision.md)

## 1. 목적 및 3차 불승인 사유 해소 방향
- **기존 문제**: `_STRUCT_OVERREACH_SUBJ_RE`, `_STRUCT_OVERREACH_PRED_RE` 내 특정 장면 낱말 사용으로 은퇴 항목에만 과적합되고 탐침에서 0건 판정됨 (규약 2-2 위반). `_DIRECT_PROOF_STRUCTURE_RE` 내 따옴표 오타(`r"(?:'r'"`) 존재.
- **해소 방향**: 장면 명사를 전면 배제하고, 메모 #156에서 승인된 본질인 **'서증 능력 범주(7대 범주) 대 주장 술어 범주(문법 부사/전칭 표지)' 간의 증명력 불일치 구조**로 재정립.

## 2. 서증 능력표 (7대 닫힌 범주)

| 서증 종류 범주 | 단독으로 증명할 수 있는 객관적 범위 | 단독으로는 직접 증명할 수 없는 범위 (비약 판정 대상) |
| :--- | :--- | :--- |
| **1. 일방 통지류**<br>(내용증명, 최고서, 통고서) | 발송·도달 사실, 통지 내용의 고지 존재 | 상대방의 승낙, 채무 승인, 통지 내용 자체의 객관적 진실 |
| **2. 견적·계획류**<br>(견적서, 공사계획서, 산출내역) | 제안 금액, 예정된 시공/용역 내역 | 실제 지급 완료, 공사/용역의 최종 완료 |
| **3. 명의·식별류**<br>(통장 표지, 사업자등록증, 신분증) | 명의자, 계좌의 존재 및 개설 사실 | 실제 금원 거래, 이체 완료, 대여금 지급 |
| **4. 진단·상태류**<br>(진단서, 소견서, 감정서) | 진단 당시의 신체/물리적 상태 | 가해자 특정, 가해 행위의 존재, 고의/과실 |
| **5. 영상·사진류**<br>(현장 사진, 캡처 화면) | 촬영 당시 시점의 외형적 상태 | 전후의 계속성, 전 기간 지속, 행위자의 내심의 의사 |
| **6. 영수·입금류**<br>(영수증, 입금증, 이체확인증) | 해당 기재 금액의 수령/입금 사실 | 별개 채무의 전액 변제, 전체 채무의 완전 소멸 |
| **7. 진술·확인류**<br>(제3자 확인서, 인우보증서) | 작성자의 진술 존재 사실 | 객관적 법률관계 확정 (C등급 한정) |

## 3. 주장 술어 범주 (닫힌 문법 표지 사전)
사건 장면 명사를 배제하고 문법적 한정/전칭 표지만 사용:
1. **전칭 · 전 기간 (문법 부사)**: `항상`, `매번`, `모든`, `계속`, `내내`, `줄곧`, `일체`
2. **내심의 상태**: `의사`, `고의`, `인식`, `공모`
3. **완료 · 확정**: `완납`, `완료`, `변제`, `이행완료`
4. **상대방 의사표시**: `승낙`, `승인`, `동의`, `합의`

## 4. 판정 논리 및 승인 조건 엄수
1. **판정식**:
   - 문장 내에서 원용된 인용 서증들의 **능력 합집합**이 주장 술어 범주를 뒷받침하지 못할 때만 `EVIDENCE_PURPOSE_MISMATCH` 판정.
   - 복수 서증이 결합 인용되어 그중 1개라도 주장 술어를 덮을 수 있으면(예: 영수증 + 계좌거래내역) 정상 결합 입증으로 보아 판정 제외 (결합 원칙 유지).
2. **승인 조건 유지 및 오타 수정**:
   - `_DIRECT_PROOF_STRUCTURE_RE` 첫 대안의 따옴표 오타(`r"(?:'r'"`) 완전 수정 및 정상 매칭 검증.
   - 일방 통지류의 경우 서면 작성 당사자와 발신인이 **'자기 측'**인 경우에만 B등급 확정.
   - 상대방 발신 통지는 상대방 의무 인정의 정당한 근거가 될 수 있으므로 판정 제외(`continue`).
   - 직접 증명 구조(`입증된다`, `증명한다`, `확인된다`)로 원용된 경우에만 B등급 확정.

## 5. 시험 계획 초안
- **양성 시험**: 7대 서증 능력 범주 $\times$ 서로 다른 주장 술어 범주 양성 7건 + 3대 변형(어순, 연결어미, 동의어) 각 21건.
- **대조군 시험**:
  1. 결합 원용 대조 (견적서 + 세금계산서 완납 입증 -> 정상)
  2. 상대방 발신 통지 대조 (피고 발신 통지서로 피고 채무 인정 주장 -> 정상)
  3. 간접 정황 원용 대조 (내용증명을 단순 독촉 사실의 간접 근거로 원용 -> 정상)
  4. 진단서로 진단 상병 입증 대조 (정상 원용)
  5. 영수증으로 해당 영수 금액 변제 입증 대조 (정상 원용)
  6. 사진으로 현장 상태 입증 대조 (정상 원용)
  7. 통장 표지로 계좌 명의 입증 대조 (정상 원용)
