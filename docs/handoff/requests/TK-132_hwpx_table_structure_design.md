## 요구별 설계

1. **구조·소유권:** 알려진 HWPX namespace URI와 local-name으로 `tbl/tr/tc/cellAddr/cellSpan`을 읽는다(prefix는 고정하지 않는다). 각 `t`는 가장 가까운 셀 또는 일반 문단 한 곳에만 귀속한다. 바깥 문단에서 셀 하위 트리를 재수집하지 않으며, 중첩 표도 독립 소유자로 처리한다. 본문·표 전후 순서를 보존하고 같은 값의 서로 다른 셀을 문자열 중복 제거로 지우지 않는다. 보이는 블록과 rendered_text에서 한 번씩 표현하되, 기존 원시 XML·숨은 텍스트의 포렌식 레이어 구분은 유지한다.
2. **표 계약:** `cells`는 문자열 2차원 배열, `table_ref`는 문서 내 안정적인 part+구조 경로 식별자로 유지한다. 셀의 원래 행·열 주소를 보존하고 빈 칸은 빈 문자열로 둔다. 병합 anchor에만 값을 두고 covered 칸은 빈 문자열로 둔다. 별도 좌표 정보에 anchor/covered 관계와 row_span/col_span을 기록하며 값은 복제하지 않는다. 블록에 table_ref·셀 좌표를 연결해 중복 계산과 문단 합치기를 막는다. 중첩 표의 값을 부모 셀 값에 다시 합산하지 않는다. 섹션 번호를 실제 페이지로 간주하거나 좌표를 만들어내지 않는다.
3. **순서:** ZIP 안의 package 문서(`content.hpf` 포함)를 명시적으로 읽고 manifest의 id→href와 spine의 idref 순서를 해석한다. archive 내부 경로만 정규화·검증하고 외부 URL은 조회하지 않는다. 누락·손상·중복 참조는 사유를 남기며, 읽을 수 있는 미참조 섹션은 숫자 순 fallback으로 뒤에 붙인다. spine을 전혀 쓸 수 없으면 전체 섹션을 숫자 순으로 정렬해 section2가 section10보다 먼저 오게 한다. 동률 순서도 경로로 고정한다.
4. **상한·부분 파싱:** 할당 전에 정수 주소·양수 span·범위·중첩 깊이·겹침을 검사한다. 초기 제안 상한은 표당 10,000행/256열/**100,000칸**, 문서 전체 200,000칸, 표 중첩 8단계이며 운영 근거가 없는 보수적 제안값이다. 행×열과 span 끝 좌표를 검증한 뒤 배열을 만든다. XML 크기·노드/텍스트 누적량에도 문서 단위 상한을 두고 기존 ZIP/XML 방어를 유지한다. 손상 표는 안전하게 읽은 텍스트·좌표와 부분 파싱 사유를 남기고 다음 표/섹션을 계속 처리한다. 불완전·겹침 표는 완전한 계산 입력으로 내보내지 않는다. 승인 후 소비자에 필요한 최소 완전성 검사를 추가해 계산·사실·증거의 표/본문 fallback 모두에서 불완전한 값을 확정 근거로 쓰지 않게 한다. 병합 의미를 해석할 수 없으면 값을 복제해 추정하지 않고 해당 계산을 미확인으로 둔다.
5. **안전·판정:** 숨은 주석·지시문은 visible 표에 섞지 않고 기존 별도 검사 경로로 보낸다. sidecar/보고서 메타데이터는 좌표·ref·상태 중심으로 하고 원문 추가 사본을 넣지 않는다. 새 동적 문자열도 마스킹·개인정보 최종 검사를 통과해야 한다. 표 안 인용이 모델 경로로 가더라도 기존 cascade_source와 전송 payload의 바인딩을 유지한다. 구조 추출 성공만으로 법령·판례 존재나 법률 판정을 VERIFIED로 승격하지 않는다.

## 측정 계획과 미측정 항목

사용자가 승인된 운영 점검에서 고정 기간·제품 SHA·입력 수집 범위를 기록하고 집계만 제공한다. 재시도를 제거한 입력 문서 N, 실제 형식이 HWPX인 H, 구조를 조사할 수 있는 HWPX P, 실제 tbl을 포함한 T를 세어 **H/N, T/P, P/H**와 조사 실패 사유를 보고한다. 파일 확장자만으로 형식을 확정하거나 현재 비어 있는 structure.tables를 ‘표 없음’으로 세지 않는다. HWPX 안의 표 포함 비율은 P=H일 때만 T/H로 확정하며, P<H이면 미조사 수와 관측 범위를 함께 남긴다. 해시 기준 고유 파일 수도 별도로 제시하고 보고서에 원문·파일명·식별자를 싣지 않는다.

현재 운영 입력 접근 권한·측정값이 없어 비율, 병합·중첩 분포, 손상 빈도, 메모리·시간·상한 적정성, 탐지 개선/오탐률은 **미측정**이다. 티켓상 고정 벤치마크의 HWPX는 0건이므로 점수 불변으로 이 경로의 효과를 입증할 수 없다. 이 변경은 표 소비를 활성화하여 탐지 결과를 바꾼다.
