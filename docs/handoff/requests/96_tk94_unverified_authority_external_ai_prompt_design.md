- **수용 기준:** 순수 프론트엔드 기능, 탐지 diff 0, 채점기 불변, 개인정보 및 본문 문맥 원천 배제, 공식 조회 상태(`official_status`) 엄격 필터, 외부 AI 전송 정책(`LOCAL_ONLY`) 준수

## 1. 개요 및 설계 의도

- **배경:**
  - 공식 DB에서 `OFFICIAL_NOT_FOUND` 등으로 확인되지 않는 판례·법령은 하급심(고법/지법) 판결이거나, 사건번호 오기, 또는 생성형 AI가 만든 가짜 판례일 수 있습니다.
  - 변호사/법무관이 서면 1건을 검토할 때, 미확인된 판례·법령 전체를 엘박스(L-Box) 등 법률 특화 AI에 한 번에 입력하여 일목요연한 답변(표)을 얻을 수 있도록 단 하나의 일괄 검증 프롬프트를 제공합니다.
- **설계 원칙 (보안 및 개인정보 보호 강화):**
  1. **인용 식별자만 포함 (본문 문맥·개인정보 원천 차단):** 서면 본문 문맥(`claim_text`)은 당사자 실명, 전화번호, 주소 등 민감한 개인정보를 포함할 수 있으므로 프롬프트에서 **100% 완전 배제**합니다. 오직 판례 사건번호(선고일자, 법원) 및 법령명/조문 식별자만 목록화합니다.
  2. **공식 조회 상태(`official_status`) 엄격 필터링:** 자의적인 판정 문장 부분일치(미확인·오류·왜곡·부당 등)를 전면 제거하고, `official_status ∈ {OFFICIAL_NOT_FOUND, UNVERIFIED_SCOPE}`인 객관적 출처 미확인 항목만 엄격히 수집합니다. (공식 확인된 항목은 배제).
  3. **외부 전송 정책(`LOCAL_ONLY`) 확인:** 프로젝트 설정이 `external_ai_policy: "LOCAL_ONLY"`인 경우 프롬프트 복사 버튼을 숨김 처리(`hidden = true`)하여 정책 위반을 원천 차단합니다.
  4. **공식 확인 아님 고지 문구 필수 포함:** 프롬프트 상단 및 UI 버튼 근처에 "외부 AI 답변은 공식 확인이 아니며, 법원 판결서 사본 또는 국가법령정보센터 공식 원문으로 최종 확인해야 한다"는 필수 고지를 명시합니다.
  5. **클립보드 복사 실패 시 Fallback 대화상자 제공:** 브라우저 권한이나 비보안 컨텍스트로 인해 자동 복사(`writeText`, `execCommand`)가 실패할 경우, 프롬프트 텍스트를 모달 대화상자(`copyFallbackDialog`)에 표시하여 사용자가 직접 전체 선택(Ctrl+A) 및 복사(Ctrl+C)할 수 있도록 보장합니다.

## 2. 프롬프트 템플릿 구조 (단일 일괄 템플릿)

```markdown
[역할]
당신은 대한민국 법률 및 판례 검증 전문 AI입니다.
아래 소송 서면에서 인용되었으나 공식 DB에서 출처가 확인되지 않은 [판례·법령 목록 {N}건]에 대해 실재 여부와 판결요지/조문 내용을 정밀 검증해 주세요.

※ 고지: 외부 AI 답변은 법적 효력이 있는 공식 확인이 아니며, 실제 변론 및 증거 제출 시에는 법원 판결서 사본 또는 국가법령정보센터 공식 원문으로 반드시 확인해야 합니다.

[기준 시점]
- {incident_date 또는 "미지정 (소송 진행 시점 기준)"}

[검증 대상 판례·법령 목록 ({N}건 - 인용 식별자)]
1. {cited_authority}
2. ...

[검증 요청 사항]
위 각 판례/법령 항목에 대해 다음 내용을 일목요연하게 표 및 요약으로 답변해 주세요:
1. 실재 여부: 실제 존재하는 판례/법령인가? (대법원/하급심 여부, 정확한 사건번호, 선고일자)
2. 판시사항/조문 내용: 해당 판례의 공식 판결요지(판시사항) 또는 해당 법령 조항의 핵심 규정 내용
3. 판례 대체/보강: 만약 위 사건번호가 존재하지 않는 가공(환각) 판례라면, 동일한 쟁점을 다룬 실제 대법원 판례 제시

[답변 형식]
- 종합 검증 결과 요약 표 (번호 | 인용 식별자 | 실재 여부 | 공식 판결요지/조문 핵심 | 비고)
- 각 항목별 상세 확인 내용
```

## 3. UI/UX 구현 명세

1. **버튼 위치 및 컨테이너 (`index.html`, `app.js`):**
   - 4열 통합 검토 표(`<table id="reviewTable">`) 래퍼 하단에 `<div id="reviewTableActions" class="review-table-actions"></div>` 배치.
   - 프로젝트가 `LOCAL_ONLY`가 아니고, `official_status`가 `OFFICIAL_NOT_FOUND` 또는 `UNVERIFIED_SCOPE`인 판례/법령 항목이 1건 이상 존재할 경우에만 `[📋 엘박스/AI 검증 프롬프트]` 소형 버튼 노출.
   - 버튼 옆에 건수 배지(`(미확인 판례·법령 N건)`) 및 "※ 외부 AI 답변은 공식 확인이 아니므로 원문 확인이 필요합니다." 고지 안내문 표시.
   - 클릭 시 클립보드 복사 및 토스트 알림 표시.
2. **복사 실패 Fallback 대화상자 (`copyFallbackDialog`):**
   - 자동 복사 실패 시 모달 대화상자를 띄우고 전체 선택 버튼 제공.
3. **스타일 (`styles.css`):**
   - `.review-table-actions`: 표 하단부에 조화롭게 결합된 컴팩트한 액션 바.
   - `.external-ai-prompt-btn`: 눈에 띄되 차분한 블루 톤의 소형 버튼.
   - `.review-prompt-notice`: 차분한 그레이 톤의 11px 고지 문구.
   - `.copy-fallback-dialog`, `.copy-fallback-textarea`: 실패 시 수동 복사용 모달 스타일.
