# TK55 occurrence-preserving transform evidence (new design; product HOLD)

The 688a84 substring-presence comparison is unsafe for argument: a removed PHONE spelling can be found inside an unrelated surviving long number, falsely authenticating the deleted occurrence. It also raises `RecursionError` for a complete deeply nested source. Neither failure is waived. Accepted product remains `86e75e3`; prior comparison tests stay historical and unchanged. This design replaces substring certification and recursive source parsing, not the fixed PII/name detectors or legacy policy.

**Occurrence evidence, not text matching:** an actual rendering step must emit an immutable positional trace while it performs its one transformation. Each output character either points to its original input index or is marked inserted/redacted. Selection carries exact original ranges; removal and pseudonym replacement mark output as non-source. Compose traces through actual steps without rerunning masking, calling the detector again for alignment, string-search authentication, edit-distance/diff alignment or guessed replacements. For a decoded character, every code-unit spelling (including 6-unit escape/12-unit surrogate pair and nested-JSON composed spans) must have consecutive source→output correspondence at the same occurrence. Candidate spans may use only selected, surviving units. Deleted/outside values cannot borrow another occurrence's spelling. Gaps do not concatenate. Every non-null origin must match the actual rendered character; indices/ranges must be monotone, unique and inside the selected source. Binding is to immutable source, selection, actual rendered leaf, consumer, original system, output schema and complete final request.

**Two producers, different availability:** claim source-text is already masked before selection. Its actual post-mask immutable source plus exact substring range supplies an identity/slice trace, with no pre-mask restoration. Argument cuts before a caller-supplied `mask`; the current pipeline callback returns only a string and exposes no verified removal/masking trace. Therefore **opaque/unattested argument callbacks must abstain from additional projection**, retaining existing final-request checks and explicitly leaving that mandatory encoded residual open. Identity rendering can supply a trace directly. Extending the actual pipeline callback requires a separately reviewed internal source-capture contract: emit strip-injection edits at the actual replacement operation and PII unchanged/replacement spans at the actual `_mask_matches` append operation, then compose them. A test-only traced renderer can demonstrate this contract with the real PII engine called once; it is not proof that today's opaque callback authenticates positions. No marker/JSON value is a capability.

**Safe source decoder:** use iterative validated JSON tokenization/string decoding and an explicit queue for encoded layers, so 1,200 structural levels do not consume Python recursion. Preserve all duplicate occurrences. Decoded work is bounded proportionally to the actual supplied source length; atomic string escapes have constant-size decoding. No new caller input-size limit or global JSON rejection is introduced. Unsupported syntax/work exhaustion/decoder failure yields `ABSTAIN_EXTRA` with a safe status, never an uncaught exception or new benign refusal; existing outer-shape validation and final-request PII inspection retain their current fail-closed behavior. This abstention is not invalid-present capability fallback: malformed source capability/binding still blocks pre-budget, with existing PII precedence. Existing argument final-leaf deep-parser refusal, where present, must be reported separately from claim's permitted incomplete leaf.

**Public comparison plan:** reproduce removed-phone support reappearing in a longer nonmatching number with different values; compare claim post-mask success, traced argument success and opaque argument abstention. Include repeated equal spellings, selected complete PHONE/RRN with quote outside, mid-token starts/cuts, nested/duplicate values, discontinuous ranges, masked/outside/excluded controls and exact payload/reservation behavior. Deep 1,200-level benign source must preserve claim baseline allowance without exception; argument baseline failure remains a separate observation. Verify single real mask invocation, mutation/trace validation and no added source disclosure. No product/old expectation/whole/CI/private changes.

**Approval boundary:** propose claim-only projection initially unless the internal actual-renderer trace contract is explicitly approved. Opaque argument abstention fixes false-block certification but does not repair its mandatory leakage; report both. PHONE/RRN-only extra projection, existing detector thresholds/name protections, four builders, retry/profile compatibility, legacy residual expectations and normal ≤6/28 remain. Full TK55 closure is not claimed.
