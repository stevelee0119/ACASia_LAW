**Codex가 빠뜨린 것**
- **자치법규(조례·규칙) 조회가 없다.**
  - ACASia 어댑터는 자치법규 대상을 조회하지 않는다. 그런데 '조례'를 일반 법령 꼴로 보아, 찾지 못하면 '존재하지 않는 법령' CRITICAL로 판정한다(`source_review.py` 344·426~431행). 실재 조례 인용에 오탐이 나는 경로다(코드 경로 확인, 운영 재현은 안 함).
  - lexdiff는 조례를 별도 노드 종류로 두고, '근거(법률→조례)' 관계와 조례 인용 패턴(`lib/link-specialized.ts` 221행)을 가진다.
- **외부 AI 답변 속 인용을 재검증하지 않는다.** `report_engine/external_answers.py`는 답변을 '공식 확인 아님'으로 보관만 한다.

- **공통 조건**
  - lexdiff 코드·프롬프트·데이터는 복사하지 않는다.
  - 공식 API(법제처 Open API)와 ACASia 데이터 계약만으로 구현한다.
  - 임계값은 별도 시험으로 정한다.
  - 새 API 대상(자치법규·3단 비교·별표)의 응답 형식은 구현 전에 실제 응답으로 확인한다(평가 측 미검증).
- **측정**
  - P0·P1·P2는 오프라인 세트로 재지 못한다.
  - 0.17.0 온라인 탐침 프롬프트(`PROMPT_FOR_ONLINE_PROBE_0170.md`)에 문서를 더하는 방식으로 탐침을 만든다: 조례 인용, 반대의견 인용, 외부 AI 답변, 위임 시행령, 처분기준 별표.
