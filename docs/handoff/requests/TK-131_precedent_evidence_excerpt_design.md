## 요구별 설계

1. **선택 후 예산 적용:** 공식 원문 전체를 로컬에서 고정하고 원문 문단·절 경계와 직접 인용의 연속 대응 구간을 찾는다. 비교용 공백 정규화가 필요하면 원문 위치 역매핑을 유지한다. 우선순위는 **직접 인용 → 필수 주변 문단(주어·요건·부정·단서) → 판시사항·판결요지 → 판단 이유·결론 → 의견 귀속**이다. 사건별 단어 사전이나 모델의 관련성 판단에만 의존하지 않는다. 공식 구조 정보가 없거나 대응이 복수이면 불명확성을 기록한다. 의견 귀속이 없으면 오독되는 구간은 귀속 문단도 필수 묶음에 포함한다. 앞부분을 자른 뒤 검색하지 않는다.
2. **EvidencePack:** `source_record_ids`, 원문 해시·길이, 선택기 버전, `segments[{segment_id,start,end,section,selection_reason,text}]`, `omitted_ranges`, `coverage`, `context_status`를 제안한다. `start/end`는 고정한 **마스킹 전 Python 문자열의 0-based Unicode code-point, [start,end)**이며 byte/UTF-16 위치가 아니다. 겹친 구간은 합치고 원문 순서로 직렬화한다. 생략 범위는 원문 전체에서 선택 구간의 여집합이다. 원문 해시·offset은 로컬 감사 기록에 두고 원문 추가 사본을 로그에 남기지 않는다.
3. **예산·불완전성:** 24,000자는 초기 원문 선택 상한으로 유지하되 수치는 승인 후 시험으로 확정한다. 문단/필수 묶음을 중간에서 자르지 않고 낮은 우선순위의 선택 묶음부터 제외한다. 마스킹 후 JSON·provider token 예산도 검사하며, 초과 시 원문 선택 단계로 돌아가 재구성한다. 전체 원문 포함이면 FULL, 필요한 묶음을 모두 확보한 발췌면 SELECTED, 필수 문맥·대응·귀속을 확보하지 못하면 PARTIAL이다. 예산 안에 필수 묶음을 넣지 못하면 `INSUFFICIENT_CONTEXT`로 남기고 해당 의미 검토의 모델 호출을 생략한다. 기존 UNVERIFIED와 사유를 유지하고 다른 인용의 처리는 계속한다. SELECTED는 판결 전체의 완전성을 뜻하지 않는다.
4. **전송·표현:** 모델 입력은 `official.evidence_pack`의 구간 목록으로 제안하며, 질문·발췌 필드·근거 미확인 설명에서 ‘전문’ 표현을 제거한다. 원천 어댑터의 실제 원문 `official_record.full_text` 저장 계약은 유지한다. `source_truncated`는 **마스킹 전 원문 길이와 선택 구간의 합집합 길이**로 결정한다. segment의 text·section·설명 및 confirmed metadata 등 동적 문자열을 기존 정책에 따라 마스킹한 뒤 그 전송용 pack으로 불변 cascade snapshot을 만든다. 새 필드도 검사 대상이며 마스킹 면제 필드나 별도 직접 provider 경로를 만들지 않는다.
5. **인용·판정:** `evidence_quotes`의 각 비어 있지 않은 인용은 실제 보낸 **단일 segment** 안에 연속해서 있어야 한다. 다른 segment·다른 source의 문자열을 이어 붙인 인용, 전송하지 않은 생략 부분은 거부한다. 내부에는 매칭 segment ID를 기록하고 기존 응답 스키마 변경은 최소화한다. 기본 의견과 escalation의 추가 의견에 같은 검사를 적용한다. 개인정보 검사·출처 바인딩 불일치·근거 부재·모델 불일치 시 기존 보수적 결과와 `advisory_only`를 유지한다. 발췌/모델 합의만으로 existence·최종 법률 판정을 VERIFIED로 승격하지 않는다.

## 측정 계획과 미측정 항목

사용자가 실행하는 다음 온라인 점검의 고정 기간·제품 SHA·profile·policy를 기록하고 평가 측이 **집계만** 검토한다. 단위는 재시도를 합친 `(보고서, 인용, 공식 원문 해시)`이며 판례 해시 기준 중복 제거 수도 함께 낸다. 대상 수 N(의미 검토 후보), 원문 확보 수 A, 실제 모델 실행 수 E, 길이 >24,000인 수 L을 구분하고 **L/A**를 보고한다. 원문 부재·빠른 검토·격리 등 미실행 사유도 분리한다.

직접 인용이 있는 원문 확보 대상 Q 중 유일하게 대응한 수 M, 복수·불일치 수를 각각 센다. 원문 offset `start >= 24000`인 대상 B와 경계를 걸치는 대상 X(`start < 24000 < end`)를 분리해 **B/M, X/M, M/Q**를 함께 보고한다. 직접 인용이 여러 개면 대상별 ‘하나 이상’과 구간별 수를 별도 집계한다. 인용문·원문·사건 식별자는 집계 보고서에 싣지 않는다. 기존 보고서에 길이/offset이 없으면 0으로 채우지 않고 ‘측정 불가’로 남겨 승인된 온라인 재실행에서만 수집한다.

티켓상 기존 온라인 점검은 의미 검토 실행 **0건**이므로 현재 길이·위치 비율은 **미측정(0%가 아님)**이다. 이 세션은 운영 보고서·비공개 원문에 접근하지 않는다. 실제 누락률, 모델별 오판 감소, 선택기 정확도, 호출 시간·token·비용은 미검증이다. 오프라인 고정 점수는 회귀 확인용이며 이 모델 경로의 개선 효과를 입증하지 못한다.
