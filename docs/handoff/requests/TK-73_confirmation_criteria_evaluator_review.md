# TK-73 확인 필요 분리 기준안 — 평가 측 검토

2026-10-11. 사용자 선택: **확인 필요 분리 설계·기준안 검토**. 현재 제품·등급·기존 시험·채점·수용 기준은 유지한다. 설계 검토 선택과 변경 승인은 구분한다. 구현/평가 역할과 기준 변경 승인은 [AGENT_ROLES](../../AGENT_ROLES.md) 1·2·5절을 따른다.

## 검토 결과와 권고

정식 제목과 설명을 구별할 원문 근거가 부족하면 **표기가 서로 다르다는 관찰**과 **서로 다른 정식 서증명이라는 확정**을 분리하는 방향이 타당하다. 확인 필요는 같은 제목이라는 인증도, 중복이 없다는 판정도 아니다. 확인할 원문·위치·전체 대안과 기존 A 근거를 보존하고 사람이 제목 역할을 판단할 수 있게 한다.

다만 현재 범위를 확대해 TK-73 완료로 수용할 근거는 부족하다. 닫힌 목록·본문 구간을 사용하는 제한형 `5cd4f04`와 날짜·EOF 확대형 `c16cc4b` 및 지원 guard 보완 `5c8b3b5`를 별도 검토한다. **날짜 확대는 기존 공개 대조에서 추가 이득 없이 진짜 중복의 확인 손실을 늘렸으므로 초기 채택 범위에서 보류를 권고한다.** 출처 지원 범위의 EOF 인증도 아직 보완이 필요하다. 열린 인용·이미지·기호 보호를 고친 것만으로 모든 원문 지원 범위를 증명하지는 못했다. 확정 여부의 의미를 바꾸려면 아래 계약을 구체적으로 승인받아야 한다.

## 같은 공개 입력에 대한 비교

아래의 진짜/오탐은 공개 합성 문서의 작성 의도에 따른 정답이다. 프로그램이 작성 의도를 증명한 것으로 해석하지 않는다. 기존 111건에 같은 새 진단을 병렬 적용한 결과와 별도 날짜·EOF 117건을 구분한다. 같은111은 평가 측 독립 실제 재집계로 원래 행/findings111/111 불변 및 아래 손익을 확인했다. 별도117과 신규54의 전체 수치는 구현 측 측정으로 구분하며 감사는 이를 중복 전체 실행하지 않았다.

## 출처·적용 범위의 한계

- 평가 측 기존4종의 설계 applicability는 앞3 원래A0/행 유지, 마지막 원래A3 중 확인 필요2/기존A1이다. 원래 AFP3은 유지된다. 채점·제품 수용 시험·새 봉인 시험이 아니다.
- 전체 원문과 기존 name/date/author/purpose의 parser 투영은 구분한다. 이름 앞부분이나 날짜를 잘라 정식 제목을 인증하지 않고, 모든 원문 대안·날짜·수식어·GLOBAL·부모/당사자/가지번호 및 원래 달력·금액·누락 경고를 보존한다.
- EOF는 지원하는 원문 끝까지 읽었다는 출처 범위 증거다. 제목/설명이 의미상 끝났다는 증거는 아니다. 읽기에서 제외된 원문 occurrence가 있으면 EOF를 인증하지 않는다.
- `c16cc4b` 공개 감사에서 마지막 이미지 PDF/DOCX 특수문자 및 열린 인용의 허위 EOF를 재현했다. 보완 `5c8b3b5`는 구현 측 실제282건에서 원래 rows/findings를 유지했고, 신규54 중 이미지3·기호3·열린 인용9의15건을 legacy로 돌렸다. 외부 namespace3은 원래 lexical 대응 실패로 legacy였으므로 새 이득으로 집계하지 않는다. 같은111/별도117의 분류는 c16과 같다.
- `5c8b3b5` 독립 실제17건에서 이미지·annotation·외부 vector·기호·unknown XML·외부 namespace·열린 인용의 거절 및 정상 대조/원래 findings 유지를 확인했다. 그러나 실제 Form 본문과 sh 음영 PDF의2건은 비char 객체가 `page.objects`에 나타나지 않아 지원/EOF를 잘못 인증했다. 객체 목록의 부재는 미지원 원문이 없다는 증거가 아니다. 원문 연산·지원 범위 증거의 새 설계부터 검토하며 제품 승인은 보류한다.
- native DOCX 표에서 원래 행이 추출되지 않는 경우도 별도 coverage 잔여다. 행 없음은 진짜 양성 보호 통과가 아니다.

## 이후 승인할 계약과 수용 기준의 구분

1. **표시/상태 계약:** 제한적으로 원문 역할이 불명확한 경고를 ‘서로 다른 표기 발견·정식 제목 확인 필요’로 표시할지 결정한다. 기존 UNKNOWN의 A/CONTRADICTED 단정 의미가 바뀌는 범위를 명시한다. A 출처 근거와 원래 관찰은 보존한다.
2. **확인 손실:** 진짜 중복이 확인 필요로 이동하는 수와 사람이 확인할 부담을 수용할지 결정한다. 모든 원래 양성 탐지 유지와 독립 확정 재현율은 각각 보고한다.
3. **측정 계약:** 원래 A 오탐/전체·대조군 오탐은 계속 기록한다. 새 확정 중복 오탐과 확인 필요 후보 지표를 추가한다면 별도 명칭·분모·기준을 정한다. 후보를 옮겼다는 이유로 기존 AFP0 충족을 선언하지 않는다.
4. **보호 시험:** 적용할 상태·표시 기대값과 원래936의 영향 가족을 먼저 명시한 뒤 평가 측이 승인된 최소 변경을 담당한다. TITLE/GLOBAL/누락·인용·다른부모·날짜·금액 및 기존 정상 보호를 유지한다. 사용자 승인 전 기존 기대값 변경0이다.
5. **티켓 완료:** 제한형 정보 분리의 수용과 전체 TK-73 해소는 구분한다. 현재 마지막 기존 A1 및 출처/행 coverage 잔여가 남는다. 구체 변경이 승인되어도 제품 구현·정확 SHA CI·원래/새 지표 판정·통합 검증·새 봉인·릴리스는 후속 절차다.
