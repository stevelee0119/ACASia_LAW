# TK73 native PDF support evidence revision (review only)

**Why the current guard is HOLD.** `pdfplumber` with its default layout settings can expose only `char` objects even when all text is inside a Form XObject or a page paints a shading. Absence from an extraction inventory is not original-source absence. Keep the exact 5c8 diagnostic and its results as history; product/status/grade/936, original111/117 expectations, scorer/gates and criteria remain unchanged.

**Proposed bounded evidence.** Separately parse each actual page's native decoded content streams with strict PDF syntax, preserving page/content occurrence order. An explicit supported text-operator grammar, operand types/arity and balanced text/graphics state must account for every parsed instruction. Resolve native resources and reject XObjects (including Forms), shading, patterns, graphics-state extensions, unknown resources/operators, malformed streams and uncertainty; never inspect only rendered/extracted object categories. In particular `Do`, `sh`, inline images and drawing/path operators are unsupported even if extraction yields no non-character objects. Declared unsupported resources also abstain rather than being silently treated as unused. Unknown catalog/page capabilities, annotations, optional content, actions and Type3 glyph programs are outside the bounded domain. Structural checks reject them rather than claiming original-source emptiness. Font resource resolution and actual referenced font names must agree; this does not certify font glyph meaning or authentic bytes.

The old decoded-native lexical occurrence mapping remains an independent necessary check. Content-stream syntax, native resource absence and extraction mapping prove different properties. This proposal certifies only the explicitly supported native source domain and ordered decoded-text extent, never title identity, semantic heading closure or a visual/OCR reading of arbitrary PDF content. Failed/unsupported proof retains legacy A. No synthetic source span, join syntax, omitted original text, reordered occurrence, registered-key waiver or foreign owner is authenticated. Global full alternatives, dates, native TITLE-A and quote/protection guards remain.

**Public precheck.** Generate three independent titles in actual ordinary-text PDF, all-text-in-Form PDF and `sh` shading PDF (nine documents); report extraction categories, native operator/resource occurrences, old/new source proof and immutable original rows/findings. Ordinary-text controls should retain the existing proposed state, Form/sh should reject usable EOF and retain original A. Add actual malformed/unknown-native-resource/operator countercontrols if the bounded parser cannot account for them. The frozen 5c8 new54 and original111/117 populations must run independently on the same files with original expectations unchanged, reporting all state changes rather than rewriting earlier outputs. Any new support failure is a disclosed abstention, not a target fix.

This is a design/capability review. No implementation or criteria approval, original AFP0, CI success, production 0.1-second bound or completed TK73 is claimed. Target applicability remains partial; native-to-reading omissions stay legacy. Source support cannot be extended from a positive extraction alone.
