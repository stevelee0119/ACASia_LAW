## 1. 배경 및 1차 불승인 반성

1차 구현(`a7497f9`)은 train 결함 문서의 고유 문구(`외에는 자료를 제출하지 않`, `번역문 만`, `복사 범위 밖`, `소리 데이터` 등)를 정규식에 반영하여, train에서는 40/40을 얻었으나 은퇴 세트(08/08b/09/10) EVI-FORM 7항목에서 득점 변화가 0이었고, 같은 결함을 다르게 쓴 문장 5건을 전혀 잡지 못했습니다. 또한 피고 서면에서 상대방 증거 탄핵 시 오탐 위험이 발생했습니다.
이에 문장 틀 정규식을 전면 폐기하고, **결함의 구조**, **작성 당사자 기준 주체 구분**, **정상 별도 제출(USB 등) 보호**에 기반한 재설계를 제안합니다.

---

## 2. 결함 판단 구조 (4대 축) 및 등급

서면이 **자기 증거로 원용하는 입증자료**에 한하여 아래 4가지 구조적 결함을 판별합니다.

1. **축 1: 파일명·자리표시만 존재 (내용·사본 부존재)**
   - 자리표시(`삽입 예정`, `추후 첨부`, `사본 별도 첨부 예정` 등)가 기재된 경우 → `SUSPICIOUS` · B
   - 서면이 특정 매체 자료를 내용 증거로 직접 원용하면서도 서면 내 사본·발췌 구역이 비어 있고 단순 파일명만 기재된 경우 → `SUSPICIOUS` · C
   - **보호:** `갑 제3호증 통화녹음(USB 별도 제출)` 등 매체 증거를 별도 물리 제출함을 밝힌 정상 기재는 결함에서 제외(정상 보호).
2. **축 2: 서면 자체의 부제출 자인 (문서 내 진술 모순) → `CONTRADICTED` · B**
   - 서면이 사실을 증명하기 위해 특정 자료를 원용하면서도, 서면 본문 스스로 "제출하지 못했다 / 제출되지 않았다 / 확보하지 못했다 / 원본이 제출되지 않았다"고 명시적으로 자인하는 자기모순 구조.
3. **축 3: 필수 기재사항(서명·작성자·날짜) 공란 양식 → `SUSPICIOUS` · B**
   - 확인서·진술서·동의서 등의 문서에서 작성자 성명, 서명/날인, 작성일자란이 공란(`(인)`, `(서명)`, 성명 빈칸 등)인 채로 제출되어 형식적 진정성립 요건을 결여한 미완성 양식 구조.
4. **축 4: 내용 식별 불가 자인 + 증명력 주장 → `CONTRADICTED` · B**
   - 서면 스스로 내용의 핵심 부분(금액, 본문, 화면 등)이 식별 불가능하거나 훼손·삭제·누락되었음을 자인(예: "지워진 빈 화면 사본", "하단이 복사되지 않아 금액을 알 수 없다", "원본 접근 불가")하면서도 이를 증거로 원용하여 사실을 증명하려는 모순 구조.

## 3. 주체 구분 및 오탐 방지: 작성 당사자 기준

- **원칙:** 단순 낱말 필터(`피고가 제출한`)가 아닌, 서면 제목 및 말미(`원고 소송대리인`, `피고` 등)를 통해 **작성 당사자(원고/피고)**를 먼저 특정.
- **탄핵 배제:** 작성 당사자의 **상대방 당사자가 제출한 증거를 지적·탄핵하는 문장**(예: 원고 서면에서의 `피고가 제출한 을 제N호증은 …`, 피고 서면에서의 `원고가 제출한 갑 제N호증은 …`, `신빙성이 없다`, `진정성립이 인정될 수 없다` 등)은 검출 대상에서 완전히 제외.
- **보수적 접근:** 서면의 작성 당사자를 확실하게 식별할 수 없는 경우에는 오탐 방지를 위해 판단을 유보(스킵).

2. `test_positive_blank_signature_form`: `작성자의 성명과 날인이 전혀 없다` (축 3)
3. `test_positive_summary_memo_without_audio`: `녹음 파일 없이 요지만 정리한 메모뿐` (축 1)
4. `test_positive_unidentifiable_content_truncated`: `하단이 복사되지 않아 합계 금액을 알 수 없다` (축 4)
5. `test_positive_media_filename_unsubmitted`: `음성파일 VOICE-01.wav만 기재되어 있고 파일 자체는 제출되지 않았다` (축 1)

### 5.2 신규 대조군 시험 (상대방 증거 지적 3건 + USB 별도 제출 2건)
