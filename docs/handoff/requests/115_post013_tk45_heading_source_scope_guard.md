# TK45 원문 첫 statement: heading 앞 UNKNOWN 보호

제품2d487ad/보고tip ae77740에서 BODY 첫 문장 한정만으로는 원래 reading source의 앞 인용/타인 도입이 닫혔음을 증명하지 못했다. 공개 actual TXT 두 반례: 열린 「 다음에 청구원인 제목+직접 부정+나중 닫힌 」, 그리고 피고 주장 도입 문장 다음에 청구원인 제목+직접 부정. 모두 baseline0→새 IMPLICIT_WRITER1이었다. 자동 source span 정확성과 BODY 첫 문장 여부는 원래 source scope 폐쇄의 증거가 아니다. 앞 보고/재반박/일반 preamble/청구취지 반대도 공개6 시험으로 제품 보완 전 고정한다. 기존143 기대값은 변경하지 않는다.

같은 승인 화자/UNKNOWN 계약의 최소 범위 축소: 새 proof는 원문 reading source의 앞 내용이 whitespace와 선택적 관측 청구원인 heading뿐이고, BODY 첫 비어있지 않은 문장일 때만 허용한다. 앞 제목이 열린 인용 안에 있거나 앞 preamble/다른 section이 있으면 새 화자 증명 없음이다. 일반 preamble이 독립 작성자의 정상 서술이어도 새 인증하지 않는 능력 제한을 명시한다. 기존 원래 finding은 계속 생성/보존한다. 인용 종료·도입 semantics를 새 sample 단어/화자 exception 목록으로 추정하지 않는다.

_sections가 정한 BODY suffix 원문 offset과 실제 grounds heading의 일치 start/end를 사용한다. heading 앞 whitespace fullmatch는 original source pos/endpos로 단 한 번 검사한다. prefix string 복사나 각 문장마다 전체 prefix 재검색을 추가하지 않고 unknown heading mapping은 abstain한다. 기존 BODY boolean/민법 결합/terminals/격·술어 증명은 유지한다. 원문 prior scope를 인증하지 않는 baseline 보존이 목적이며 새로운 consumer 면제·사실/이행/완료 인증·rule ID·보호/원장/설정/버전/CI 변경은 없다.

새6 반대와 기존143/양성6 및 실제 format controls를 관련시험으로 제출하고 정확 제품 SHA의 독립 좁은 감사/CI/3줄 요청 후 원래 정상8/8와 부정·확장 각각 시작 대비 증가 게이트를 기다린다. TK44/49 전체 UNKNOWN 잔여와 TK45 완결은 이 guard로 주장하지 않는다.
