# TK73 current proof limitation and independent next work

No TK73 product change is approved in this post-0.13 branch. Both diagnostics leave original findings unchanged. The source-only198 experiment yields no complete-identity certificates; the bounded108 experiment yields nine proposal candidates under a separate explicit-equality/coordinate-only contract. These are public capability measurements, not proof that the outstanding acceptance condition is satisfied. No prior rejected product has been transplanted.

The missing capability is a certified **complete title / complete remainder role boundary**, together with an independent relationship for the complete identity. Original reference occurrences and exact ordered native lexical pieces can prove which text was read. They cannot, by themselves, prove that arbitrary trailing text is a location rather than a subtitle, edition, condition or qualification. A coordinate token found somewhere inside that text does not certify the rest. A finite sentence ending does not certify an affirmative identity assertion: negation, uncertainty, embedding and substantive qualifiers remain part of the complete proposition. More whitespace normalization, first-separator clipping, registered-key exemptions and source-only metadata do not supply these missing proofs.

A safe bounded solver remains possible where independent source evidence exists. The108 proposal has three independent constraints: source-proved closed inventory roles, an entire coordinate-only remainder, and a native whole-line equality for an exact plain complete title. It transforms neither body prose nor dates and vetoes every original global alternative or uncertain origin. It is independently implementable after design review and original936/GLOBAL/UNKNOWN validation; it is a separate improvement, not a substitute for the unresolved TK73 acceptance condition. Compatibility-created operators, qualified/free remainders, literal coordinate-title differences and legacy-truncated original names remain UNKNOWN.

A broader implementation needs additional evidence that can actually be verified: original presentation regions that independently own complete title and non-title fields, or a separately validated complete-caption relationship. Any region must be proved by original source occurrences/context, not inferred from balanced punctuation, a generic heading or arbitrary formatting alone. Any relation must preserve complete propositions, all original global alternatives and unknowns. A morphological ending test does not provide that relation. A semantic model would require a separate grounded-proof design and bounded runtime validation; it is not implemented or assumed correct here.

Production native capture also needs a reviewed lifecycle: request-local ownership/protection flags and intervals outside document serialization, with no duplicate raw source strings added to cache/log/export/masking/LLM payloads. Cache reload, changed reading coordinates, substitutions or masked content invalidate the proof to UNKNOWN. PDF decoded extraction characters are not encoded raw-glyph evidence. The diagnostic geometry provider is not production code and has no production runtime certificate.

Next preparation is concrete: retain the public198 ambiguity controls and108 bounded contrasts, require source-occurrence/role positive and genuine-opposite proof for any new capability, then propose only the minimum certified comparison projection. Original fields, populations, date/amount/list-missing paths, TK64, all prior936 expectations, the0.1s processing requirement and acceptance gates stay unchanged. Current blocked status is unresolved role proof and product approval; there is no completed TK73 fix or acceptance claim.
