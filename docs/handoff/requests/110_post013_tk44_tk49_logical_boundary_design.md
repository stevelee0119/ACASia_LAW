**Proposed first product phase: independently evidenced primary correction.** Capture balanced marked-content invocation identity, original decoded logical-text ranges and original glyph indices during the same PDF interpretation; MCID is a label, never a unique identity. At an adjacent reconstructed paragraph boundary, require one uniquely covering logical span, exact glyph order/coverage, exact raw visible text on both sides, no overlapping replacement, unresolved/rotated/hidden/OCR source, unsupported decoding, added instructions or unaligned text. Locate a source separator only from that exact logical-to-glyph mapping: empty logical separator→JOIN; one source U+0020→SPACE. No-space glyphs, line fullness, font, geometry and extractor agreement cannot provide JOIN. Preserve mapping through subsequent normalization as ranges; do not assert one normalized character per glyph. Direct glyph SPACE remains authoritative under the current contract; a conflicting replacement cannot override it and is an explicit rejected provider witness. Apply accepted explicit signal through existing keyword-only API before legacy heuristics; untouched/unsupported documents reproduce the current primary string, floor and61 protections. Existing hidden-instruction inspection still receives original replacement content; source mapping does not make that content safe.
