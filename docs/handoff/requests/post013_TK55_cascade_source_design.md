# TK55: cascade source-preservation precheck (not product approval)

Base `2a85aa0`. Previous value-only comparison `c758e81` is rejected for product use: six ordinary-noun placements were newly refused. Legacy role atoms remain unresolved; no original gates/expectations change.

**Actual consumer and loss.** `VerificationPipeline` calls `router.cascade` (`pipeline.py:1326`) with an official record and a document extract. `cascade` makes Primary/Critic/Grounder requests (`router.py:561/606/634`). `_build_prompt` (`:762`) turns the question, `official` object, optional primary verdict and document into headings/JSON/UNTRUSTED prose. Whole-string JSON parsing then fails. Consequently an encoded JSON string or Unicode-escaped number inside source evidence may lose the structural/decoded context that the existing lossless walker would retain. The document wrapper grants no privacy exemption. This consumer is distinct from the existing four fixed-envelope builders.

**Proposed bounded mechanism.** Preserve an immutable inspection-only snapshot of exactly the source portions rendered by `_build_prompt` (question, official record, document, optional primary verdict) at the actual three construction sites. Bind it to the exact rendered user payload, exact original stage system and `_VERDICT_SCHEMA`. The product proposal would use an internal frozen source type constructed by this consumer, not a JSON/metadata marker. Re-rendering the frozen snapshot must equal the original provider user payload; malformed, substituted or mismatched source records fail closed before budget. A supplied marker or output schema alone cannot create that provenance. No new person-type or role vocabulary is introduced. Source inspection uses the current lossless walker and detectors, scans all decoded/duplicate values, and preserves PII_INPUT_BLOCKED precedence. Continue scanning original system, assembled request, dynamic schema and metadata too. An authenticated source adds inspection; it does not exempt the rendered text or any field.

**Payload and compatibility.** Keep `_build_prompt` output and provider system/user/schema bytes unchanged. Store no raw source in receipts; report only codes, paths and hashes. No special field is sent to the provider wire adapters. Freeze source content before dispatch so later mutations cannot disagree with the inspected request. Critic binds the actual returned primary verdict; grounder binds only the original question/evidence, as today. Provider fallback and transient retry carry the same source snapshot and re-use the existing reservation rules. Deterministic/QUICK early returns remain early returns. Legacy direct callers without this internal context retain their behavior and known role residuals. Escaped evidence in such callers is not silently declared fixed. No extra model calls, network requests, dependencies, settings, limits or output fields.

**Comparison-only public spike.** Instrument the actual `_build_prompt` calls in tests to retain an out-of-band immutable snapshot, then add current-detector source inspection at actual `inspect_request` before reservation; this proves causal context recovery without prematurely modifying products. Compare baseline/spike on three phones/RRNs/names, Unicode-escaped/duplicate/nested strings, official/document/critic reply positions, three benign institutional/legal controls, forged JSON markers and source/payload mismatch. Confirm payload equality, provider/reservation counts, all three roles, fallback/retry behavior, and unchanged existing four-builder and legacy residual expectations. New source name contexts may expose existing overblocking, so explicitly report any benign new refusals. A clean spike is only evidence for root's unchanged mandatory/name/normal precheck; arbitrary untyped-role closure remains unproved.
