## Changed product path

Argument's actual internal pipeline renderer captures the same immutable source used by `context[:1000]`. Actual `strip_injections` replacements and PII `_mask_matches` appends emit unchanged-index/unowned-insertion evidence during their one execution. Ordinary callers keep their original strip/mask calls. Opaque callbacks render normally and record `ABSTAIN_NO_TRACE`. There is no observer, traced string subclass, mask replay, diff or substring authentication in product code.

Claim captures only its actual **post-mask** full source and selected prefix/keyword-centered slice. Both producers create request-local immutable, repr/deepcopy/asdict-redacted context. Exact original/assembled system, output schema, consumer, actual leaves and complete ordered batch coverage bind the context. Actual profile rendering can rebind unchanged authenticated leaves; invalid prior context remains invalid. Each truncated single retry gets only its own item proof. Option-only replace retries retain proof; request/content/schema changes or source removal fail closed. Output schema is copied without changing wire order/content.

The additive pre-budget decoder inspects surviving PHONE/RRN units only, preserving existing detector kinds/thresholds, all original request scans, PII precedence and budget behavior. Immutable capability structure/types/ranges/source correspondence validate before decoder abstention. Every duplicate/nested/escaped occurrence stays separate, complete escapes/surrogates are atomic, gaps do not concatenate, and deleted/masked/outside source is never restored.

Capture is limited to 65,536 source characters and 131,072 trace units; exceeding the trace bound stops further trace allocation. Over-limit pieces retain no additional original source and truthfully report `ABSTAIN_CAPTURE_LIMIT`, preserving actual rendering/exceptions and existing input checks. Iterative decoding has proportional work `8 × source length + 64`, avoiding recursive object construction. Unsupported/work/known decoder failure abstains from extra projection, with explicit safe statuses. Unexpected inspection failures still use the existing fail-closed router. This bounded extra inspection leaves opaque, unsupported/over-budget and unmeasured upstream-loss residuals; it does not globally close legacy JSON.
