# TK73 native page-tree support proof (review only)

The 464 native-grammar review remains HOLD. A page whose `/Parent` points to a separate empty `/Pages` can still be reached through catalog `/Kids`; checking ancestor types/keys alone does not prove membership. An external `/F` content stream also falls outside the helper's supported-source claim: the existing product parser fails before comparison, so full EOF is unmeasured, not a successful abstention or usable certificate. Product/criteria/936 and frozen 5c8/464/54/111/117 diagnostic expectations remain unchanged.

**Narrow proof.** Traverse the actual catalog `/Pages` indirect-reference graph, in native Kids order, independently of the reader's flattened page view. Require a real root with no parent; every internal/leaf child has exactly the traversed parent reference; each internal node has a typed Kids array and integer Count matching its actual descendant leaves. References belong to this reader, resolve in range, and are visited once: cycles, duplicate/reused nodes, dangling/direct/uncertain references, inconsistent links and unsupported node capabilities reject support. Compare the resulting exact leaf-reference sequence/cardinality to the reader's actual page occurrences before using page content support. Native reference identity is file-local metadata, not a semantic title or global row identity. One forward iterative traversal accounts for nodes/edges/counts; no ancestor-by-every-page Cartesian proof or permissive repair is added.

Native page content streams must also belong to the supported embedded-stream grammar: external file keys `/F`, `/FFilter`, `/FDecodeParms`, unknown stream capabilities or non-stream values reject before decoding. Do not fetch external content, replace it with empty text or claim that a product parser exception proves EOF. The earlier native operator/resource checks and lexical-to-reading mapping stay independent requirements. A valid page tree proves declared page membership/order only; it does not prove glyph meaning, whole-file metadata relevance, OCR completeness, source-role equality or semantic heading closure. Unsupported proof keeps legacy A if an original finding is available; parser failure/row-free input is recorded separately as unmeasured.

**Public comparison.** Generate three-title actual ordinary PDFs, valid nested page trees, mismatched parent, inconsistent count, duplicate/cyclic/dangling references and external streams, plus genuine GLOBAL full-date conflicts. For parsable documents assert original rows/findings unchanged and report old/new proof/tier separately; for parser failures report only isolated native-proof rejection and the exception class, never A/EOF success. The frozen 464/new21 and 5c8/new54/111/117 actual files run unchanged and retain their expected results; any extra abstention is disclosed. Source omissions, all-origin GLOBAL alternatives, independent TITLE-A, calendar findings and trailing protection remain.
