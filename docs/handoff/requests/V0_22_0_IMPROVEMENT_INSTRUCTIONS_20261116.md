## 3. 잘 작동한 기능 vs. 개선이 필요한 기능

### 잘 작동한 기능
* **규칙 기반 포렌식 및 보안 격리**: 흰 글자, 제로폭 문자(`U+200B`), 렌더링 레이어 불일치를 놓치지 않고 탐지해 `quarantined: true` 및 Vector Index 자동 등록 차단(`rag_indexable: false`)으로 즉시 격리함.
* **허위·왜곡 인용 1차 적발**: 존재하지 않는 법률명(`행위는지방계약법`, `노무회복법`, `군훈련안전보장특별법`), 범위 초과 조문(`민법 제1500조`, `근로기준법 제999조`), 법원–사건부호 불일치(`2022헌바999`, `2021고합1234`), 판시 취지 역전(`2021헌바86`)을 모두 포착해 `release_gate: BLOCK`으로 연결함.
* **달력·요일·수치 정합성 검사**: 윤년이 아닌 `2025. 2. 29.`, `2025. 4. 31.` 및 실제 일요일인 `2025. 11. 16.(월)`, 호증 결번(`갑 제7호증`), 합계 비율 오류를 정확히 산출함.

### 개선이 필요한 기능 (구현 과제)

#### [P0-1] `ai_hallucination_table` 인용 항목–AI 의견/가이드 매핑 어긋남 수정
* **현상**: `documents[0].ai_hallucination_table`(61행)에서 `citation_id`·`cited_authority`와 `ai_opinions`·`legal_reasoning`이 서로 다른 항목과 밀려 결합됨(예: `CIT_8ca1dbd08bef`[국가배상법 제2조 제1항] → `노무회복법 제12조/근로기준법 제999조` 의견, `CIT_3814f8fe3fce`[행위는지방계약법] → `지침 제1조` 의견, `CIT_be15a7762251`[국가배상법] → `88다카2813` 의견). 또한 법령·지침 행에도 일괄적으로 `"공식 출처 확인 및 판결서 인터넷 열람 안내"`(판결서 사본 요구)가 출력됨.
* **구현 지시**:
  1. 리스트 인덱스 기반 병합(`zip`)을 제거하고 `citation_id` 키 기반 딕셔너리 조인으로 고정할 것.
  2. `actionable_guidance`를 인용 유형(`STATUTE`, `ADMIN_RULE`, `CASE`)별로 분기해 법령·행정규칙에는 국가법령정보센터/소관 규정 원문 확인 가이드를 출력할 것.

#### [P0-2] `INPUT_PRIVACY_BLOCKED`로 인한 `ai_detection` 전면 실패(0자 검사) 해소
* **현상**: 총 97회 LLM 호출 중 17회(Anthropic 7/59, Gemini 3/8, OpenAI 7/30)가 `INPUT_PRIVACY_BLOCKED [MASKING_PII_DETECTED:PII_INPUT_BLOCKED]`로 실패함. 특히 `ai_detector_result`는 3개 모델 모두 실패(`inspected_chars: 0 / 35,674`)해 휴리스틱(`UNCERTAIN 0.4`)만 남음.
* **구현 지시**:
  1. `payload-pii-v4` 2차 검사에서 마스킹 완료 토큰, 법령 조문 번호, 판례 사건번호가 PII로 재탐지되지 않도록 1차 마스킹 규칙과 2차 검사 정규식을 동기화하고 화이트리스트를 적용할 것.
  2. 2차 검사 차단 시 즉시 실패 처리하지 말고 추가 마스킹 패스 1회 후 재시도하는 복구 경로를 추가할 것.

#### [P1-1] 구 사건부호(`다카` 등) 형식 오탐 및 판례 DB ID 매칭 오류 수정
* **현상**: `88다카2813`(`CIT_8ab3c61993e5`)은 `law_go_kr`에서 공식 판례(`id: 104530`)가 조회되었으나 형식 검사기가 구 부호 `다카`를 미지원해 `IMPOSSIBLE` 및 `LEGAL_ARGUMENT_INVALID`로 오탐함. 또한 `2021헌바86`(`CIT_00ad995c48d9`)의 `claim_evidence.source`에 타 사건 `2015나11341`(`id: 193303`)이 잘못 매칭됨.
* **구현 지시**:
  1. 사건번호 유효성 사전에 구 사건부호(`다카`, `나카` 등)를 반영할 것.
  2. 외부 판례 DB 조회 결과를 `claim_evidence`에 결합할 때 사건번호·법원명·선고일 일치 검증 가드를 추가해 불일치 매칭을 차단할 것.

#### [P1-2] 현행 기본 실정법 `temporal_pending` 과다 처리 및 무리한 법리 주장 독립 탐지 강화
* **현상**: `헌법 제29조·제27조`, `국가배상법 제2조`, `민법 제390조·제750조` 등 현행 기본 법령 26건이 `temporal_pending`으로 `PARTIALLY_VERIFIED`에 머무름. 한편, 무리한 법리 주장 4종(시효 30년, 일방 증액 300%, 민사 무죄추정, 하급심 법률 폐지)이 인용 오류와 분리된 독립 법리 검토 항목으로 명확히 표출되지 못함.
* **구현 지시**:
  1. 과거 시점이 쟁점화되지 않은 기본 실정법은 최신 시행일 기준으로 `VERIFIED` 처리하고, `VERIFIED` 법령은 `ai_hallucination_table` 미확인 목록에서 제외할 것.
  2. `argument_validity` 단계에 대표적 법리 오류 패턴(소멸시효 기간 왜곡, 민·형사 입증책임/무죄추정 혼동, 하급심의 법률 효력 폐지 주장, 계약 일방 변경 등)을 인용 오류와 분리해 독립 플래그로 보고하는 프롬프트/룰을 보강할 것.

#### [P2-1] 인용 경계 파싱, NER 불용어 필터 및 부속서 메타표 제외
* **현상**: `행위는지방계약법`(조사 결합), `최소한 동 지침 제5조 제1항`(부사 결합) 경계 오류, NER 오탐(`부대`, `측에`, `영위하는`, `대한민국` PERSON, `민간` COMPANY), 부속서 K 테스트 메타표(`CIT_1fd1a609f653`) 본문 주장 혼입.
* **구현 지시**: 법령 추출기 선행 부사·후행 조사 스트리핑, 한국어 법률 NER 불용어 필터, 부속서/체크리스트 메타표 제외 휴리스틱을 적용할 것.

#### [P2-2] Google Drive RAG 12,000자 절단 해소, 지침 매칭 및 실행 속도 개선
* **현상**: `reference_review`가 앞 `12,000자 / 29,536자`만 대조해 후반부가 누락되고, Drive 내 군 안전규정이 본문 `지침` 6건과 연결되지 않아 모두 `NOT_FOUND` 처리됨. 전체 실행 시간 약 17분 20초, `llm_prompt_caching: false`.
* **구현 지시**: `reference_review`를 청크 분할 대조로 전환해 전체 본문을 커버하고, 약칭 `지침`에 문서 내 정의문·Drive 규정 제목을 결합한 쿼리 확장을 적용하며, `llm_prompt_caching` 활성화 및 청크 병렬 처리로 속도를 개선할 것.

## 4. 회귀 테스트 완료 기준 (Acceptance Criteria)
1. 동일 테스트 서면 재실행 시 `state`가 `PARTIAL_COMPLETED`가 아닌 정상 완료 상태로 종료될 것.
2. `INPUT_PRIVACY_BLOCKED` `0건`, `ai_detector_result.signals.coverage.model_executed == true` 및 `inspected_chars > 0` 달성.
3. `ai_hallucination_table` 전 행에서 `citation_id`와 `ai_opinions`·`actionable_guidance` 유형이 100% 일치할 것.
4. `88다카2813` 오탐 제거 및 `2021헌바86` 근거 내 타 사건(`2015나11341`) 미혼입.
5. `reference_review`가 문서 후반부(29,536자 전체)를 대조해 Drive 규정과 본문 `지침`을 매칭하고, 무리한 법리 주장 4종이 독립 리스크로 탐지될 것.
