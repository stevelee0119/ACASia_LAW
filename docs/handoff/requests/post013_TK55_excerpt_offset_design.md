**Selection mapping:** validate the complete producer source as JSON, retaining every duplicate/nested value. Decode each string character with its entire original-source interval: ordinary character 1 unit, ordinary escape 2 units, Unicode escape 6 units, surrogate pair one character/12 units. Compose intervals through encoded JSON string layers. A character is available only when its entire spelling belongs to a selected range. Group contiguous available characters; never concatenate across omitted ranges or complete a partial escape. Detect with the existing detector/threshold in those selected decoded fragments. A numeric candidate is admissible only if its complete raw supporting interval belongs to one selected range **and that exact spelling survives in the actual rendered masked leaf**. A closing quote may be outside selection. Malformed/untyped original prose is not reinterpreted as JSON syntax. Additional projection is PHONE/RRN only; existing name/other PII inspection stays unchanged, with no new role/name inference.

Existing masker/selection order, limits and wire bytes are preserved; masking is never rerun to validate a request. In the public prototype, mixed plaintext+encoded contacts preserve both existing transform orders and still block the surviving encoded contact. Explicit instruction-removal controls are absent from rendered support and remain allowed.
