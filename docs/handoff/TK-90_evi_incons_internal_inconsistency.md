# TK-90 문서 안 진술 불일치(EVI-INCONS) 재현율이 낮다 (P2, 탐지, 설계 메모 먼저, 평가 측 발견)
- 발견: 평가 측, 2026-10-19 손실 유형 측정(오프라인, Steve `f5bc6c0` = 0.13.1 제품 코드). 근거는 집계뿐이다.

## 1. 증상 (집계)
- 은퇴 4세트: 21항목 중 득점 3.0(0.14). 오프라인에서 결정적으로 잡을 수 있는 유형 가운데 손실이 가장 크다(18항목).
- 개발 말뭉치 첫 기준(10-16, `b68cfee`): train 0.20, check 0.20(각 40항목). 중점 6유형 중 하나다.
- 고정 dev·holdout에는 이 유형 항목이 없다. 따라서 릴리스 점수를 바로 올리지는 않고, **은퇴 세트·말뭉치 일반화 점수**로 잰다.

## 2. 설계 메모에 담을 것 (승인 전 구현 금지)
1. 같은 대상(금액, 날짜·기간, 당사자 역할, 횟수·수량, 장소)을 문서의 서로 다른 곳에서 다르게 적은 경우를 구조로 찾는 방법. 대상 식별(같은 사건·같은 항목인지)과 비교 규칙.
2. 정당한 차이(정정 진술, 가정적·예비적 주장, 상대방 주장 인용, 기간 계산상 다른 기준일)를 거르는 방법.
3. 기존 검사(EVI-NUM·EVI-DATE·사건 일지 날짜 분석)와 겹치지 않게 하는 경계. 공용 입력은 바꾸지 않는다.
4. 정규식 성능(점검표 2항)과 예상 오탐.

## 3. 수용
- 점검표 1~7항. train에서만 오르거나 평가 세트 문구 일치로만 오르면 불수용. 고정·은퇴 오탐 0·A등급 0 유지.
