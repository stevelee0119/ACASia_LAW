# TK-84 내부 참고자료 대조 결과의 모델 의견·인용이 80·120자에서 잘려 표에 보인다 (P2, 표시 결함, 기존)
- 유형: 표시 결함. 탐지·채점 규칙 변경이 아니다.
- 발견: 사용자 보고(2026-10-19, 개선안 3가) → 평가 측 코드 확인.

## 1. 증상
- `packages/verification_engine/candidate_verifier.py` 108~111행(TK-70 참고자료 모순 승격)이 결과 제목을 만들 때 다음처럼 자른다.
  - 모델 의견(`candidate.explanation`): 80자
  - 서면 주장 인용·참고자료 규정 인용(`claim_quote`·`basis_quote`): 상세 설명에서 120자
- 확인할 항목 표는 이 제목을 '상세 보기' 문구로 보여 준다. 그래서 의견이 문장 중간에서 끊긴다.

## 2. 요구
1. 제목은 짧은 고정 문구(참고자료명 + '내부 참고자료 대조 — 법적 구속력 미판단')로 둔다. 모델 의견은 제목에 넣지 않는다.
2. 모델 의견 전문과 두 인용 전문(근거 `excerpt` 상한 300자는 유지)을 표 본문에서 펼쳐 볼 수 있게 한다. 긴 글은 접기(`details`)를 써도 되지만, 잘린 채로 끝나면 안 된다.
3. 등급(C)·상태(SUSPICIOUS)·위험 지수 제외(`gate.py` 159·238행)는 그대로 둔다.

## 3. 시험·수용
- 의견 200자·인용 200자짜리 합성 후보로 제목·상세·화면 표에 전문이 나오는지 확인한다(실제 진입점 시험 1개 포함).
- 탐지 diff 0, 고정·은퇴 점수 불변(동일 조건 대조).
