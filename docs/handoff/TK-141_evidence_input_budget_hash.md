## 2. 수정(수정본 내용)
- `_router_input_cap(router)`: 라우터의 `limits["max_input_tokens"]`(없으면 설정값).
- `_excerpt_budget_chars(cap, document_text)`: 문서 문장·과업 문구 여유(4,096)·시스템(2,048)·정밀 검토 1차 판단(4,096)·고정 1,024 바이트를 뺀 나머지를 4로 나눈 글자 수. 발췌 예산 = min(24,000, 이 값). 기본 한도에서는 24,000 그대로.
- 발췌가 예산에 안 들면 기존 PARTIAL 경로(모델 미호출)에 '공급자 입력 한도 N에 맞춘 발췌 예산 M자'를 덧붙인다.
- `_sized_cascade`: 보내기 직전 라우터와 같은 함수(`_build_prompt`)로 실제 요청 바이트를 다시 재고, 한도를 넘으면 부르지 않고 UNVERIFIED '공급자 입력 한도(N)를 넘어…'.
- 리뷰에 `evidence_pack.sent_sha256`(실제로 보낸 발췌, 가림 적용 뒤 글자의 SHA-256)과 `input_budget`(한도·예산·추정 바이트).
- 과업 문구 줄은 원래 자리에 그대로 둔다(평가 세트 문구 대조 관문이 옮긴 줄을 새 줄로 센다).
