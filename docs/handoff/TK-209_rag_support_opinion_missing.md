# TK-209 지지 참고자료가 선별되나 '지지' 의견이 생성되지 않는다

- 발견일: 2026-11-19 (운영 온라인 점검, PR #340 I-2)
- 출처: 배포 `32d9c485` 운영 온라인 점검 3회 전부 재현. `RAGC-S3` 미충족
- 종류: 기존 기능 개선. 0.23.0 회귀로 단정하지 않는다.
- 범위: **0.23.0 포함** (2026-11-19 사용자 결정 "I-1·I-2를 0.23.0에 넣고, 온라인 회차를 한 번 더 돌리자")
- 상태: open

## 관찰된 사실 (운영)

3회 모두 같다.

| 항목 | 기대 | 실제 |
|---|---|---|
| `RAGC-S1` 지지 자료가 대조 자료로 선별됨 | 참 | **충족** |
| `RAGC-S2` 지지 자료에서 거짓 '모순' 없음 | 거짓 | **충족** |
| `RAGC-S3` 지지 자료에서 '지지' 의견 1건 이상 | 참 | **미충족** |
| `RAGC-N1`·`N2` 무관 자료 선별·의견 없음 | — | **충족** |

선별 관문과 거짓 모순 금지는 정상이다. 선별 **이후**가 문제다.

## 이 항목의 성질 — 모델 판단 축이 섞여 있다

명세 `tests/fixtures/probes/case9_state_compensation_rag_controls_online.json`의 `RAGC-S3` 라벨은
**"지지 자료에서 '지지' 의견이 1건 이상 나온다(모델 판단)"**이다. 대조 자료 README도 지지 자료를
"case9 서면의 주장과 **같은 방향의 의무**를 적는다"로 설계했다. 식별자 일치가 아니라 내용 판단이다.

따라서 `AGENT_ROLES` 2.1 (가)(모델 판단·외부 자료가 필요해 규칙으로 풀 수 없는 것)에 걸린다.
**모델이 SUPPORTS를 내도록 강제하는 것은 이 티켓의 목표가 아니다.** 목표는 아래 3단계 중
어디에서 끊기는지를 가려 규칙으로 풀 수 있는 부분을 고치는 것이다.

## 평가 측 코드 경로 특정 (오프라인 정적 분석, SHA `556dac84`)

SUPPORTS가 생기는 자리가 둘뿐이다.

1. **결정적 경로** — `packages/rag_engine/review.py:157` 및 `:538`
   `"relationship": "SUPPORTS", "method": "DETERMINISTIC_CITATION_COMPARISON"`.
   입력 서면의 **인용 식별자**(조문·판례 번호)가 참고자료 발췌에 그대로 있을 때만 붙는다.
   지지 대조 자료는 식별자 일치용으로 만들어지지 않았으므로 이 경로로는 나오지 않는 것이 정상이다.
2. **모델 경로** — `packages/rag_engine/review.py:28`
   `"relationship": {"enum": ["SUPPORTS", "CONTRADICTS", "CONTEXT", "INSUFFICIENT"]}`.
   `RAGC-S3`가 겨냥하는 경로다.

## 할 일 (구현 측) — 진단이 먼저다

아래 세 지점을 실행 기록으로 분리해, 다음 온라인 회차에서 어디서 끊기는지 보이게 한다.

1. **발췌 전달.** 선별된 지지 자료의 어느 발췌가 모델 입력에 실제로 들어갔는지(자료 id·쪽·발췌 길이)
   를 남긴다. 발췌 범위가 좁아 '같은 방향의 의무' 문장이 프롬프트에 없었다면 **규칙 문제이고 고친다.**
2. **모델 응답.** 모델이 돌려준 `relationship` 분포를 자료별로 남긴다. 모델이 `CONTEXT`·
   `INSUFFICIENT`만 냈는지, `SUPPORTS`를 냈는지 구분한다.
3. **승격·부착.** 모델이 `SUPPORTS`를 냈는데 관측치에 남지 않는다면 임계값·승격·부착 단계에서
   떨어지는 것이다. `CONTRADICTS` 승격 경로(`tests/test_tk70_rag_contradiction_promotion.py`가
   보호하는 자리)에 대응하는 `SUPPORTS` 경로가 있는지 확인하고, 없으면 **그것이 결함이다.**

진단 결과 2번(모델이 내지 않음)만 남으면 그것은 (가) 축이다. 그때는 고치지 말고 기록하고,
평가 측이 명세 처리 방법을 사용자 결정으로 정한다.

## 수용 기준

1. 세 지점이 실행 기록에서 분리되어 보인다
2. 1번·3번에 결함이 있으면 고쳐지고 합성 자료 시험으로 증명된다
3. 프롬프트를 바꾸는 경우, '지지 의견을 내라'는 지시를 넣어 모델을 편향시키지 않는다.
   거짓 지지는 거짓 모순과 같은 무게의 결함이다. `RAGC-N2`(무관 자료에 지지·모순 없음)와
   `RAGC-S2`(지지 자료에 거짓 모순 없음)가 계속 충족되어야 한다
4. 기존 시험 전부 통과, 은퇴 세트 후퇴 없음, 고정 세트 점수 이동 없음, 엔진 오류 0
