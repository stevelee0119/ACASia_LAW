# TK-189: 참고자료 상세 재렌더 시 펼침 상태 소실

발견: 2026-11-16 (Asia/Seoul), 0.21.0 평가 중에도 별도 사본 재현 이력 있음. P2, 기존 결함. 상태 open. 담당 Antigravity.

운영 `183f3d22791bb01d4c8a39ce842e193000c663b8`의 실제 HTML/JS/API 응답을 사용한 브라우저 제어 재현에서 `#referenceStatus > details`를 연 뒤 같은 실행 결과로 `renderFindings()`를 호출하면 `open=true → false`. 실제 서버 결과는 바뀌지 않았다. 이 실험은 동일 데이터의 통제된 재렌더 재현이며 특정 CI 실패의 실제 이벤트 순서를 입증한 것은 아니다. 일반 브라우저 직접 TLS 연결은 평가 환경의 인증서 신뢰 문제로 미완료여서, TLS를 검증하는 urllib 실응답 전달 경로를 사용했다. 합성 서버 응답으로 바꾸지 않았으며 직접 모바일 시험 통과로 확대하지 않는다.

원인: `apps/web/static/app.js`의 `renderFindings()` 약 3180행에서 referenceStatus를 `replaceChildren()` 한 뒤 닫힌 details를 새로 만든다. `referenceStatusLine` 약 2517행에 상태 복원이 없다.

보완: 같은 프로젝트·같은 실행 ID에서만 바깥 상세 및 사용자에게 필요한 내부 상세의 펼침 상태를 보존한다. 프로젝트/실행이 바뀌면 새 문맥으로 초기화한다. 전체 페이지에 하나의 전역 open 플래그를 두지 않는다. 출처 원문/XSS 처리·문서별 소속·링크는 유지한다.

수용: 사용자 클릭으로 펼침 → 같은 실행의 필터/정렬/새로 그리기 뒤 유지, 닫힘도 유지, 다른 프로젝트/다른 실행 전환 때 초기화, 부모/자식 details 상태, 1440px/390px에서 접근 가능. 기존 출처 묶음·링크·XSS·모바일 시험 유지. 실제 이벤트 경로와 통제된 함수 재현을 모두 기록한다.

0.21.0에서 외부 사본 수정 통과 이력은 있으나 현재 0.22.0에 대한 보완 사본/관련 시험은 미검증이다. 새 수용 근거로 과거 사본 결과를 그대로 재사용하지 않는다. 제품 직접 수정 없음.
