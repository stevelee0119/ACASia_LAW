## 3. 버전 — 'V1.0.0'에 대하여
- 이 명세의 변경은 화면·보고서 기능 변경과 제거라서 버전 정책상 minor(**0.20.0**)에 해당한다(VERSION_POLICY 표: changed·removed).
- 1.0.0은 안정성 이정표이며 5.1절 조건을 모두 충족해야 한다.
  1. 공개 인터페이스(REST API·보고서 형식) 문서 확정
  2. 새 봉인 세트로 직전 릴리스와 같은 조건 측정
