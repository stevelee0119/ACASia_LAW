## 발견 내용

분석 전체 텍스트와 근거 검색 범위가 완전히 연결되지 않으면 문서 후반의 관련 근거가 누락될 수 있었다. 행정규칙 약칭이 미래의 인용이나 복수 후보에 잘못 묶일 수 있었고, 동시 모델 요청 상한을 두지 않으면 온라인 처리량·비용과 응답 안정성에 영향을 줄 수 있었다.

## 구현 반영

PR #327은 전체 `analysis_text` 근거 연결, 인용 위치 이전의 유효한 명칭만 사용하는 행정규칙 별칭 결속, 복수·중복 후보에서의 fail-closed 동작 및 Python/JavaScript 동등성을 추가했다. LLM 동시성도 제한한다.

## 운영 수용 기준

- 전체 분석 텍스트의 관련 근거가 후보 선정·검토에 포함되고, 주장과 근거의 원문 위치가 맞는다.
- 인용보다 뒤에서 정의된 명칭은 앞선 인용에 소급 결속되지 않으며, 모호한 약칭은 임의 확정되지 않는다.
- 브라우저와 서버의 별칭 결속 결과가 일치한다.
- 온라인 동시 요청에서도 설정 상한이 지켜지고, 초과 요청은 통제된 대기·실패로 처리된다.
- 외부 API에 잘못 연결된 행정규칙 이름이 조회되지 않으며, 미확정 상태를 사실 확인으로 표시하지 않는다.
