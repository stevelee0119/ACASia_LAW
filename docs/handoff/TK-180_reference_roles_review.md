# TK-180 요구 취지 재평가 — 입력 문서와 판단 기준 자료의 역할 분리

평가일: 2026-11-15(한국). 대상 #300 `35201c7f`, 보완 사본 `8784ca0d`.

## 사용자 추가 원문
> 생성 여부, 부정확한 인용, 무리한 주장 여부를 판단하는 기준이 되는 데이터(공식DB, RAG 등)은 '검증대상'이 아니라, 공식적으로 검증이 완료된 것으로 '검증대상'이 적정한지 검토하는데 필요한 자료이므로 지시문 탐지 등을 할 필요가 없다는 의미야.
> 그리고 현재 구현 의도를 적용하면서 검증대상인 입력 '법률문서' 의 프롬프트 인젝션 등 지시문 탐지 등이 제외되거나 기능이 약화되어서는 안돼.

## 판정
**핵심 처리 경로는 반영됨. 모델에 전달하는 역할 표현은 보완 필요. 최종 수용은 보완 및 CI 이후.**
앞선 평가는 사본 일치·지시형 문자열 보존을 확인했지만, 문서 검증 대상과 판단 기준 자료의 역할까지 충분히 점검하지 못했다. 새 요구를 원문 대응표에 추가한다.
