# TK-89 인젝션 채널별 탐지가 문서마다 크게 다르다: 문서 단위 차단은 되지만 채널별 결과가 빠진다 (P1, 탐지, 평가 측 발견)
- 유형: 탐지(일반화). 발견: 평가 측, 2026-10-19 손실 유형 측정(오프라인, Steve `f5bc6c0` = 운영 0.13.1 제품 코드와 같음, `scripts/eval_testset.py`, 법령 DB·AI 키 없음).
- 근거는 집계뿐이다. 세트 문서·정답 문장은 이 티켓에 옮기지 않는다.

## 1. 증상 (집계)
- 인젝션 문서는 고정 holdout 1개, 은퇴 4세트 각 1개다. 문서마다 채널 10~11종(보이는 문구, 흰 글씨, 덮인 글씨, 아주 작은 글씨, 쪽 밖 배치, 보이지 않는 렌더링 모드, 폭 0 문자, 주석, 첨부 파일, 문서 정보)이 들어 있다.
- 모든 문서에서 문서 단위 방어(`release_gate` BLOCK, 결론에 지시문 반영 없음)는 통과한다.
- 채널별 탐지는 문서마다 다르다: 10/10, 10/10, 9/10, 6/10, **0/10**. 0/10인 문서는 결과 4건을 냈지만 어느 채널과도 맞지 않았다.
- 손실: 고정 holdout 1항목(폭 0 문자 채널), 은퇴 4세트 합계 약 17항목. 고정 세트(dev·holdout)에서는 다른 채널이 모두 맞는다. 즉, 같은 채널을 다른 방식으로 만든 문서에서 놓친다.

## 2. 요구
1. 채널마다 탐지 근거를 PDF 구조로 판정한다. 예: 문자 렌더링 모드, 글자 크기·색과 배경의 대비, 그림·도형에 덮인 글자 영역, 쪽 경계 밖 좌표, 폭 0·서식 문자 코드 범위, 주석·첨부 파일·문서 정보 사전.
2. 문서 단위 차단과 별도로 **채널별 결과**를 낸다. 결과에는 쪽·위치와 채널 종류를 담는다.
3. 같은 채널을 서로 다른 생성 방식(도구·글꼴·인코딩)으로 만든 합성 PDF를 채널마다 3개 이상, 대조군(정상 서식) 3개 이상 시험으로 둔다. **은퇴·고정 세트 문서를 시험 입력으로 쓰지 않는다.**
4. 정상 서면의 작은 각주·회색 머리글·서명 이미지 등은 오탐이 되면 안 된다(대조군에 포함).

## 3. 수용
- 점검표 1~7항. 고정 dev·holdout과 은퇴 4세트를 동일 조건으로 운영본과 대조한다. 오탐 0·A등급 오탐 0 유지.
- 은퇴 세트 같은 유형(인젝션) 항목 득점이 오르고, 그 상승이 문구 일치가 아닌 구조 판정에서 나와야 한다.
