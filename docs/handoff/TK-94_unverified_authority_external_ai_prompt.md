# TK-94 출처 미확인 판례·법령 외부 법률 AI/엘박스 일괄 검증 프롬프트 생성 기능

- **발행일:** 2026-10-20 (사용자 피드백 반영 개편)
- **구분:** 화면·사용자 편의 기능 (탐지 diff 0)
- **우선순위:** 0.14.0 릴리스 반영 과제 (사용자 요청)

---

## 1. 배경 및 문제 정의

- **현행 한계:**
  - 서면에 인용된 판례나 법령 중 대법원 종합법률정보·국가법령정보센터 공식 DB에서 확인되지 않은 항목(`OFFICIAL_NOT_FOUND`, `CITATION_UNVERIFIED`, 오기 의심 등)은 하급심 판결, 비공개 판결, 미간행 판례이거나 생성형 AI가 지어낸 판례 환각(Hallucination)일 가능성이 있습니다.
  - 실무자(변호사, 군법무관)는 이를 확인하기 위해 **엘박스(L-Box)**나 법률 특화 AI 플랫폼에 직접 사건번호와 서면의 주장 내용을 일일이 복사·편집하여 검증해야 하므로 번거로움과 비효율이 발생합니다.
- **개선 목표 (단일 일괄 프롬프트로 통합):**
  - 서면 전체에서 출처가 확인되지 않거나 인용 오류가 있는 판례·법령 목록을 취합하여, 엘박스나 법률 AI에 한 번에 붙여넣기만 하면 실재 여부·판시사항 일치 여부·대체 리딩 판례까지 일목요연하게 표 형태로 회신받을 수 있는 **최적화된 일괄 검증 프롬프트 1개**를 원클릭으로 제공합니다.
  - **위치:** 미확인 판례/법령 정리된 표 하단부에 `[📋 엘박스/AI 검증 프롬프트]` 소형 버튼 단일 배치. 클릭 시 즉시 클립보드에 복사되고 토스트 알림 표시.
  - **개인정보 배제 원칙:** 판례·법령의 실재 여부 검증에 불필요한 당사자 개인정보는 일체 포함하지 않으며, 업로드 시점에만 개인정보 안내를 받도록 한 개편 원칙(TK-85)에 맞추어 프롬프트 내 사족 안내 문구도 완전 배제합니다.

---

## 2. 수용 기준

1. **표 하단 단일 버튼 배치:**
   - 미확인 판례/법령 정리된 표 하단부(`reviewTableActions`)에 `[📋 엘박스/AI 검증 프롬프트]` 소형 버튼 1개만 단정하게 배치되어야 한다.
   - 개별 행이나 요약 배너에는 불필요한 중복 버튼을 노출하지 않는다.
2. **단일 일괄 프롬프트 구성:**
   - 서면 내 출처 미확인 판례/법령 전체를 목록화하고, 3대 법률 검증 요구사항(① 실재 여부, ② 판시사항 부합 여부, ③ 대체 판례)을 표 형태로 요청해야 한다.
3. **개인정보 및 사족 문구 배제:**
   - 판례·법령 인용 표기, 서면 주장 요지, 1차 진단 결과만 담고, 당사자 실명 및 불필요한 개인정보 주의 안내문구를 일체 포함하지 않는다.
4. **엔진 무영향 (탐지 diff 0):**
   - 백엔드 탐지 로직, 채점기(`eval_testset.py`), 점수 기준선(`score_gate.py`), 보호 경로에 일절 영향을 주지 않아야 한다.
