# TK-94: 출처 미확인 판례·법령 표 하단부 엘박스/AI 일괄 검증 프롬프트 기능

- **담당:** Antigravity (구현 에이전트)
- **요청자:** 사용자 직접 지시 (2026-10-20, 10-21 2차 보완)
- **목적:** 출처가 확인되지 않는 판례·법령에 대해 엘박스 등 외부 법률 AI에 한 번에 입력하여 일목요연한 답변을 얻을 수 있는 단일 일괄 검증 프롬프트 복사 버튼 제공.
- **수용 기준:**
  1. 프롬프트에 당사자 개인정보 및 본문 문맥(`claim_text`)을 일체 배제하고 인용 식별자(판례 사건번호, 법령 조항)만 포함.
  2. 필터는 `official_status in {"OFFICIAL_NOT_FOUND", "UNVERIFIED_SCOPE"}` 기준으로 엄격히 제한.
  3. 프롬프트 및 UI에 "외부 AI 답변은 공식 확인이 아님" 필수 고지 포함.
  4. 외부 AI 전송 정책이 `LOCAL_ONLY`인 프로젝트에서는 버튼 숨김 처리.
  5. 자동 복사 실패 시 텍스트를 직접 복사할 수 있는 Fallback 대화상자 제공.
  6. 순수 프론트엔드 변경, 탐지 diff 0, 채점기·점수 게이트 영향 0.
  7. 행동 시험(`tests/test_external_ai_prompt.py`) 8건 전원 통과.
