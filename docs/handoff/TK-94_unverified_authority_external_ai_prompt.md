# TK-94 출처 미확인 판례·법령 외부 법률 AI/엘박스 검증 프롬프트 생성 기능

- **발행일:** 2026-10-20
- **구분:** 화면·사용자 편의 기능 (탐지 diff 0)
- **우선순위:** 0.14.0 릴리스 반영 과제 (사용자 요청)

---

## 1. 배경 및 문제 정의

- **현행 한계:**
  - 서면에 인용된 판례나 법령 중 대법원 종합법률정보·국가법령정보센터 공식 DB에서 확인되지 않은 항목(`OFFICIAL_NOT_FOUND`, `CITATION_UNVERIFIED`, 오기 의심 등)은 하급심 판결, 비공개 판결, 미간행 판례이거나 생성형 AI가 지어낸 판례 환각(Hallucination)일 가능성이 있습니다.
  - 실무자(변호사, 군법무관)는 이를 확인하기 위해 **엘박스(L-Box)**나 법률 특화 AI 플랫폼에 직접 사건번호와 서면의 주장 내용을 일일이 복사·편집하여 검증해야 하므로 번거로움과 비효율이 발생합니다.
- **개선 목표:**
  - 시스템이 이미 추출·보유하고 있는 인용 정보(판례명, 사건번호, 서면 내 주장 요지, 1차 진단 결과)를 활용하여, 엘박스나 법률 AI에 붙여넣기만 하면 실재 여부·판시사항 일치 여부·대체 리딩 판례까지 일목요연하게 회신받을 수 있는 **최적화된 검증 프롬프트**를 원클릭(`[📋 엘박스 검증 프롬프트]`)으로 제공합니다.

---

## 2. 수용 기준

1. **단건 복사 기능:**
   - 판례·법령 인용 오류 또는 출처 미확인 항목 행에서 `[📋 엘박스 검증 프롬프트]` 버튼 클릭 시, 해당 항목에 최적화된 마크다운 검증 프롬프트가 클립보드에 복사되고 토스트 알림이 표시되어야 한다.
2. **다건 일괄 복사 기능:**
   - 서면 내 출처 미확인 항목이 1건 이상 존재할 경우, 미확인 섹션 상단에서 `[📋 미확인 판례 전체 검증 프롬프트 복사]` 버튼으로 전체 목록을 일괄 질의할 수 있는 프롬프트를 제공해야 한다.
3. **개인정보 및 보안 안내:**
   - 프롬프트 생성 시 시스템 내부의 마스킹된 텍스트를 기본 활용하고, 외부 AI 입력 전 당사자 개인정보 포함 여부를 재확인하도록 하는 안내 문구를 프롬프트에 포함해야 한다.
4. **엔진 무영향 (탐지 diff 0):**
   - 백엔드 탐지 로직, 채점기(`eval_testset.py`), 점수 기준선(`score_gate.py`), 보호 경로에 일절 영향을 주지 않아야 한다.
