## 4. 권고
1. **A를 권고한다.** 품질에 영향이 없고 실행당 약 15%를 줄인다.
   - 효과가 크지는 않다. 대신 구현이 작고 위험이 낮다.
   - 배포 뒤 `cache_read_tokens>0`과 실제 비용을 확인한다.
2. **모델 교체는 B부터 확인 실측(구현 없음)을 먼저 한다.** 절감 여지가 가장 크고, 환경변수만으로 잴 수 있다.
   - Anthropic 한도가 회복된 뒤(2026-12-01 이후)에 한다.
   - 운영에서 `LV_ANTHROPIC_REVIEW_MODEL=claude-haiku-5-5`로 case9 ×3을 돌린다. 비용은 회당 약 $0.1이다.
   - 비교 항목:
     - 강한 관계 짝 일치(Sonnet끼리 재현 9/10을 기준으로)
     - RAG 명세 5/5
     - 근거 대조 통과율(원문 그대로 옮긴 인용만 남는 비율)
     - `CONTRADICTS` 오표시
     - 지연
   - 측정 시간 동안 다른 사용자의 검토 단계도 Haiku로 돈다. 그래서 사용자 승인과 측정 창이 필요하다.
