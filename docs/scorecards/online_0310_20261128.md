- 매 실행마다 저품질 쪽이 있는 파일 2개가 재처리 한도 120초에 걸려 실패한다(`reprocess_failed` 2). 나머지는 예산 부족으로 미룬다(`reprocess_deferred` 3→3→1). 정상본은 보존된다(TK-247 동작).
- 남은 재처리 대상 파일은 배포 직후 5개에서 측정 뒤 **3개**로 줄었다(데이터셋 상태 API `pending_low_quality_reprocess`). 파일마다 2회 실패하면 멈추므로 **2~3번의 실행 안에 끝날 것으로 추정**한다(미검증).

- 재처리를 하위 프로세스에 맡기는 설정 기록(`child_ocr_config`)이 '폴백 꺼짐'으로 남아 있다. 0.30.2 m1 복원(설계상 폴백 끔) 때 값이 그대로 남은 것으로 보이며, 재처리가 실제로 폴백 없이 도는지는 이 기록으로 판단할 수 없다(미검증).
