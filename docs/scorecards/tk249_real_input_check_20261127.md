## 2. 실제 영향(코드 확인)
- 2단계(`nli_verifier`)는 운영 기본값이 `LV_LEGAL_NLI_MODE=shadow`다(`packages/common/config.py:198`). 기록만 하고 판정·보고서에는 반영하지 않는다(`verifier.py:631-642`). 고정값 0.85도 보고서에 확률로 나오지 않는다.
- 1단계 결과는 보고서에 `CASE_QUOTE_MISMATCH` **'직접 인용문 표현 차이'**(`SUSPICIOUS`·`MEDIUM`·B등급)로 나온다. 바뀐 어절('이사회가'→'주주가')이 함께 표시되므로 **놓치지는 않는다**(`verifier.py:1510-1545`).
- 문제는 두 가지다.
  - 의미가 바뀐 치환인데도 등급이 `HIGH`·A가 아니라 `MEDIUM`·B로 낮게 붙는다.
  - 상세 문구가 "의미를 바꾸는 말(정도·부정·양태·조문 한정어·수량)은 바뀌지 않았으나"라고 단정한다. 명사 치환에는 부정확하다.

## 3. 개선 등급과 비용 대비 효용
- **등급: 추정 결함.** 합성 자료에서만 재현됐고 실제 입력에서는 0건이다. 영향도 '누락'이 아니라 '등급·문구 과소 표시'다.

| 항목 | 내용 |
|---|---|
| 효용 | 실제 입력 영향 0/513 정답 항목, 0/13 운영 인용 대조 |
| 비용·위험 | 명사 치환을 '의미 변경'(`HIGH`·A)으로 올리면 정상 바꿔쓰기(동의어·약칭·기관 명칭 변경)에서 **A등급 오탐** 위험이 있다. 오탐 게이트는 A등급 오탐 0이 기준이고, 오탐 함정 항목이 109개다. 축 조합 점검표 작성과 사전 검증 비용이 중간 수준이다 |
| 기존 시험 충돌 | `quote_diff` 관련 기존 시험과 충돌할 가능성이 있다(미검증) |
| 기회비용 | 0.31.0의 남은 일(릴리스 후보 판정·배포·Drive 온라인 실측)이 늦어진다 |
